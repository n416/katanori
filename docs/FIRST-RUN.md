# はじめての電源投入（机の上・筐体なし）

> **目的: 電池 → PowerBoost → ハブ基板 → ReSpeaker が立ち上がり、会話が 1 回できるのを見る。**
> この 1 枚だけで足りるように書いてある。[POWER.md](POWER.md) を開く必要はない。
> 穴番号の正は [relay_board.html](../hardware/parts/relay_board.html)。この紙には書かない（口の名前だけで書く）。
> 半田付けは無い。挿すだけ・全部あとから抜ける。

## 今日は繋がない物

- **スピーカー**（イヤホンで聴く。アンプはまだ一度も鳴らしていない部品なので今日はやらない）
- INA226・リードスイッチ・マスタートグル・OLED（動いてから 1 つずつ足す）
- **PC の USB**（🔴 電池と PC を同時に挿さない。書き込みしたくなったら先に電池の JST を抜く）

## 手順（この順のまま）

1. **電池はまだ挿さない。**机の脇に置いておく。
2. 線を 2 本挿す: PowerBoost の **`5Vo`** → ハブの **PWR の口の「5V」**、PowerBoost の **`GND`（`5Vo` の隣）** → **PWR の口の「GND」**。メス-メスの DuPont でよい。
   ⚠ PWR の口の 2 本目は意図的な空き。何も挿さない。**EN は今日は未接続でよい**（未接続＝オン。切りたいときは JST を抜く）。
3. ハブの **XIAO の口（7 本）** ↔ **XIAO のヘッダ**を繋ぐ（束がまだ無ければメス-メスの DuPont 7 本）。
   並びの正は relay_board.html と XIAO のシルク。**5V の 1 本がどのピンに座るかだけ、挿す前に指で追って確認。**
4. **挿す前の検査は 1 つだけ**: テスター DT10B を**導通レンジ（音が出るレンジ）**にして、PWR の口の「5V」と「GND」に当てる。
   **鳴りっぱなし（0Ω）なら短絡なので、電池を挿さずにここで戻ってくる。**一瞬鳴って止まる・鳴らないは正常。
5. イヤホンを 3.5mm に挿し、**耳からは離して机に置く**。
6. 電池の JST を PowerBoost の JST へ挿す。
7. 見る: PowerBoost の LED が点くか。起動の途中で**「カチッ」と鳴るのは正常**（ミュートリレーが閉じた音）。
   異臭・部品の発熱・LED が消えるなどがあれば**即 JST を抜く**。
8. いつもどおり会話を 1 回。聞こえたら、それが **「電池で動いた」の現行機で最初の実績**。
9. 終わったら JST を抜く。

## 詰まったときの見分け（2026-09-02 の実機で出た）

**症状: `[I2C] scanning bus...` の次の行が出ず、そのまま帰ってこない。**
`[CODEC] 応答がありません (0x18)` も一緒に出て、板の上の相手まで黙る。

**原因は AS5600 の `GND` が挿さっていなかったこと。** つまみの GND は二股で `DIR` にも
行っているので、**2 本とも抜けていた**。GND が浮いた AS5600 が SDA/SCL からバスを掴んで、
スキャンが 1 アドレス目で止まる。

⭐ **居ない相手なら即座に「居ない」と返る。帰ってこないのは「バスを握られている」とき**で、
この 2 つは別物である。切り分けはこの順で早い（1 段ずつ USB を抜いてから挿し替える）。

| 段 | 繋ぐもの | 通れば分かること |
|---|---|---|
| 1 | XIAO の 7 本も抜く（ハブごと切り離す） | `0x18` が出れば ReSpeaker と XIAO は健康 |
| 2 | XIAO の 7 本だけ戻す（OLED・つまみ・電流計はハブから外す） | 通ればハブの板は無罪 |
| 3 | OLED を足す | `0x3C` が出れば OLED は無罪 |
| 4 | つまみを足す | ここで止まればつまみ側 |

**症状: コーデックが設定されない（`creg` が `0x1B=0x00` か `0x3F=0x14`・`P1 0x09=0x00`）。音が出ない。**

原因は **XIAO の `5V` の線が `D10` に挿さっていた**こと（2026-09-02）。`D10` は ReSpeaker 側の
`I2S_MCLK` で、XMOS が出しているクロックである（[RESPEAKER-LITE.md](RESPEAKER-LITE.md) 104 行）。
そこへ 5V が入ると、XMOS がコーデックを設定できず、DAC 電源も出力ドライバも落ちたままになる。

⚠ **このとき、ログが案内する「USB を抜き差しすれば XMOS が設定し直す」は効かない。**
挿し間違いが残っている限り何度やっても戻らないので、**復旧手段が効かないこと自体を手掛かりにする。**
切り分けは上の表と同じで、ハブを切り離して `creg` を撃つと一発で分かる（切り離せば正常値に戻る）。

**症状: `beep` が聞こえない。**
`beep` の振幅は 600 / 32767 ＝ **フルスケールの 1.8%** で、イヤホンで確かめるための値である。
**スピーカーでは室内で聞こえない。** スピーカーの確認は `beep2`（振幅 4000 ＝ 12%）を使う。
⚠ 耳から離した状態で鳴らすこと。

⚠ **発熱が無いことを先に確かめる。** 熱があるならバスの話ではなく、旧ボードを壊した
ときの絵（バス死＋発熱）なので、通電を続けない。

✅ 全部つながると `0x18`（コーデック）・`0x36`（つまみ）・`0x3C`（OLED）・`0x42`（XMOS）・`0x44`（電流計）が
出て、スキャンは一瞬で終わる。⚠ **`0x42` だけは起動直後の自動スキャンに出ない**——XMOS の起動が
ESP32 より遅いためで、しばらく経ってから `s` を撃つと出る。**出ていなくても異常ではない。**

## シリアルの見張り

`python firmware/serlog.py` を回しておくと、**抜き差しに追従して**ログを取り続ける
（`serial.log` へ時刻付きで追記・`cmd.txt` に書いた1行を機体へ送る）。
`s` `creg` `knob` `mic` `beep` を撃ちながら読めるので、2 人で作業するときはこれを使う。
