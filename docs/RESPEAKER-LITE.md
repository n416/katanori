## 2. 面の呼び方（固定）

**面は向きで呼ばない。載っている物で呼ぶ。** スタンドで傾けると上下・表裏の意味が
変わるため。「上・下・表・裏」は使わない。

| 呼び方 | どの面か |
|---|---|
| **XIAO面** | XIAO・XU316・全コネクタ・パッド類が載っている面 |
| **マイク面** | マイク2個・各LED・Usr/Muteボタン・`seeed studio` ロゴがある面 |

**短辺を「左端」「右端」と呼ぶ。基準の向きは「XIAO面を手前・XIAOのUSB-Cが左」**
（✅ ユーザー確認済み・2026-08-03）。この向きで **86mm が横・34mm が縦**。

> 🚫 **鏡像の禁止（2026-08-04）。** モックで面のY割り当てを逆に置き、モデル全体が
> 鏡像になる事故を起こした。鏡像は一瞬正しく見えるため、**それを基準に伝えられる
> 座標ごと汚染される**。座標系や面割り当てを定義・変更したら、**XIAO面ビューの
> レンダを実物写真と並べて照合するまで、そのモデルで設計しない。**
> モックの面ラベル「XIAO」が鏡文字に見えたら、裏（マイク面）を見ている。

### 🔒 XIAO の14本が基板上で何に繋がっているか（📄公式回路図の断片・2026-08-14）

Seeed は**フル回路図を公開していない**（フォーラムで要求が出たまま）。ただし wiki に
**XIAO ブロックだけの回路図画像**が1枚だけ載っていて、そこに全ピンの行き先がある
（📄 `files.seeedstudio.com/wiki/SenseCAP/respeaker/respeaker_lite_v1.0_sch_1.png`）。

🔴 **「ファームで未使用＝空きピン」ではない。基板側の結線を先に見る。**
D10 をリレー駆動に選んで実機で外した件（[POWER.md](POWER.md) の D10 の節）は、この表があれば起きなかった。

| XIAO | 基板上の行き先 | 空きか |
|---|---|---|
| **D0** | 🔴 `XIAO_WS2812` — RGB LED のデータ線 | ❌ 下記 |
| **D1** | 🔴 `XU316_RST` — XMOS のリセット | ❌ |
| **D2** | `XIAO_D2` → 外部パッド1 ⑬ | ✅ |
| **D3** | `XIAO_D3` → 外部パッド1 ⑬ | ✅ |
| D4 | `I2C_SDA`（**4.7kΩ プルアップ実装済み** R34） | I2C |
| D5 | `I2C_SCL`（**4.7kΩ プルアップ実装済み** R35） | I2C |
| D6 | `I2S_DIN_SEC`（DIN・R36 0Ω） | ❌ |
| D7 | `I2S_DIN_XIAO`（DOUT・R40 0Ω） | ❌ |
| D8 | `I2S_LRCK`（R39 0Ω） | ❌ |
| D9 | `I2S_BCLK`（R38 0Ω） | ❌ |
| **D10** | `I2S_MCLK`（R37 0Ω） | ❌ **実測（1.49V＝矩形波の平均）と一致** |
| 3V3 / GND | 基板の 3V3 / GND | — |
| **5V** | 🔒 **`+5V` ネットに直結**（C59 100nF が付くだけ。逆流防止も分離も無い） | 給電の入り口 |

#### 🔒 D0 は壊れていない。**680Ωでプルアップされている**

D0 の節点はこうなっている。

```
XIAO D0 ──[D11 ショットキー]──┬──[R75 680Ω]── +3V3
                              │
XU316 ────[D12 ショットキー]──┴──[Q5 LBSS138 レベルシフタ]──[R69 5.1k→+5V]── WS2812 の DI
```

**XIAO と XMOS が1本の LED データ線をワイヤードOR で共有していて、Highを作っているのは
R75 の 680Ω。** 「何も繋がない状態でテスター(10MΩ)を当てても3.3Vが動かない」という
実測は、**このプルアップそのもの**である。🔒 **故障説は否定された。**

⚠ **ただし空きピンにはならない。** 使えば RGB LED のデータが壊れ、XMOS 側も同じ線を叩く。
⬜ RGB LED を捨てる前提なら入力として使える可能性はあるが、XMOS が叩く分を
ファームで無視できるかが未検討。**いま結論を出さない。**

### 🔒 スピーカーソケット J2 は **PH2.0**（2026-08-10 確定）

秋月の **コネクター付コード 2P(E)**（通販コード 105683・型番 DG01032-0009-01・
**JST PH相当の2.0mmピッチ・ストレートプラグ・長さ160mm**）が
**この機体のスピーカーソケットに実際に挿さる**ことを、ユーザーが現物で確認した。
規格の推定ではなく嵌合そのものを見ているので、これで確定として扱う。

[SHOPPING.md](SHOPPING.md) 2章にあった「**買う前にスピーカー端子を見ておくこと**」は、
これで解消である。スピーカー側も PH2.0 のコード付きを選べば、基板側は半田付けなしで
抜き挿しだけで繋がる。ハブ基板に載せる **IN / OUT の2ピンポスト**（[SHOPPING.md](SHOPPING.md) 5章）も
PH2.0 で確定してよい。⚠ ただし **PH2.0 は 2.0mm ピッチなので、ユニバーサル基板の
2.54mm 格子には素直に載らない**という問題は、そのまま残っている。

**向きは トップ型（真上に挿す）**。ユーザーが現物で確認した（2026-08-10）。
コードは XIAO面から真上に出るので、**この上に線の曲がるぶんの空間が要る**
（5.5 の「線込み15」がそれ）。

**場所取りは公式CADの 7.00 × 7.95 × 6.84 をそのまま使う。**

### 🔒 マイク面に載っている部品は、基板全体で **6つだけ**

STEPでZ<0側（マイク面）に置かれている部品を全部並べるとこれで終わる。

→ **マイク面の左上、左から0〜20 × 下から19.5〜34 は完全に無地**（20 × 14.5mm）。
ここは⬜（未取得）ではなく📄（公式CADで空だと確認済み）。**左のロックが掴める場所はここ。**
マイク U4 の上端は下から18.75なので、下から19.5より上なら音の穴に掛からない。

## 6. 🔒 設計に効くこと

**実測マップ（5.5）から機械的に出てくる結論。** 迷ったらここへ戻る。

1. **両方の短辺と、上辺の右角が塞げない。** 右端にジャックの筒とスピーカーの線、
   左端に XIAO の USB-C、**上辺の右角（X76〜88）に USB-C が上向きに開く**
2. **下辺の占有**: X0〜14 スイッチ ／ X32〜65 中央領域（下端まで）／ X68〜83 ジャック。
   **素の基板を下辺で掴めるのは X20〜32 の間だけ**（マージン込みで X21.5〜31 の約10mm）
3. **XIAO面は一切押さえられない**（ピンヘッダー2列＋ワイヤー、高さ10mm）
4. **マイクは長辺方向の両端寄りに1個ずつ。** マイク面を受けるなら中央だけ。端は開ける
5. → **基板は立てる。** マイク面＝前（マイクが人を向く）／XIAO面＝後ろ（ヘッダーと線は背面へ）
6. → **受け（橋）は X21.5〜31 の1個だけにして、他は全部開放する。**
   当たれる物を1個にすれば、当たりの原因も1個になる。
   X合わせは手探りにせず**左端ストッパー**に突き当てる
7. **中央領域を掴む・挟む設計は、面ごとの振り分け（⚠）を測るまで作らない**
8. **隅の穴（左2.492／上2.430・φ2.20）は、左を掴むための本命。**（2026-08-08改訂。
   旧記載は「M1は保持には弱い」だったが、径がφ2.2＝M2と分かって前提が変わった）
   φ2.2あれば**φ2.0のダボが立てられる**ので、ネジを使わずに位置を出せる。
   下側の穴（左60.202／下2.657）は基板を沈めた時点で使えないのは変わらない。
   樹脂にネジは切らない（レジン①は経時で脆い）のも変わらない
9. **左を掴むなら相手はマイク面**（5.6）。XIAO面は8項のとおり触れないが、
   マイク面は基板全体で6部品しか載っておらず、**左から13.6〜39.9 は全高が無地**、
   **左から0〜20 × 下から19.5〜34 も無地**。マイク U4（左から4.16〜6.81・
   下から15.25〜18.75）とスイッチ2つ（下から4.1〜7.4）だけ避ければよい

刷る前に全部出ていた:

|---|---|

| マイク面のスイッチが座に当たる | スイッチの箱が座と干渉する |
| 中央領域の部品を 1.5mm の座に入れようとしていた | 厚みが合わないのが見える |
