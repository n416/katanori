## 1. 基本 — この機体は **V1.1**

基板のシルクに **`V1.1`** と印字されている（✅ 実物写真 2026-08-04）。
🔴 **[公式wikiのピンアウト図](https://wiki.seeedstudio.com/xiao_respeaker/)に写っているのは V1.0 で、
別の版である。図から位置を読み取ってはいけない**（2回外している。実際「USB-Cは右の短辺」と
読んだが、この機体では上の長辺にあり開口は上を向いていた）。**図から使ってよいのは
「どの部品がどちらの面のどの端にあるか」だけで、mm は 5.5／5.6 の表からしか取らない。**

| | 値 | 出典 |
|---|---|---|
| 横（長辺） | **86 mm** | 📄 公式仕様と ✅ 実測が一致。⚠ **これは張り出し込みの外形**（素の基板は 82.024・5.6） |
| **縦（短辺）** | **34 mm** | ✅ ユーザー実測。**2枚目のボードでも34を確認**（別個体で一致）。⚠ 公式仕様の 35 と1mm食い違うが、個体差ではない。**実測を採る** |
| **板厚** | **1.85 mm** | ✅ ユーザー実測（2026-08-10・板厚ゲージv2の櫛・0.05刻み）。**公式CADの1.510とも標準の1.6とも違う。** 傍証2つ: 穴Aペグ（当て面から2.21）の出しろ「ほぼ無し」＝2.21−1.85=0.36 ／ 中央領域の実測4.8 ≒ 1.69+1.85+1.19=4.73 |
| → 溝で受けるときの設計値 | **2.10 mm** | 1.85 ＋ 縮み0.1 ＋ 遊び0.15 |

⚠ 検索に出る「45.5 × 86.5mm」は公式の外形と食い違う（ケースか梱包の値と思われる）。採らない。

## 2. 面の呼び方（固定）

**面は向きで呼ばない。載っている物で呼ぶ。** スタンドで傾けると上下・表裏の意味が変わるため、
**「上・下・表・裏」は使わない。**

| 呼び方 | どの面か |
|---|---|
| **XIAO面** | XIAO・XU316・全コネクタ・パッド類が載っている面 |
| **マイク面** | マイク2個・各LED・Usr/Muteボタン・`seeed studio` ロゴがある面 |

🔒 **基準の向きは「XIAO面を手前・XIAO の USB-C が左」**（✅ ユーザー確認・2026-08-03）。
この向きで **86mm が横・34mm が縦**で、短辺を「左端」「右端」と呼ぶ。

> 🚫 **鏡像の禁止。** モックで面のY割り当てを逆に置き、モデル全体が鏡像になる事故を起こした
> （2026-08-04）。鏡像は一瞬正しく見えるため、**それを基準に伝えられる座標ごと汚染される。**
> 座標系や面割り当てを定義・変更したら、**XIAO面ビューのレンダを実物写真と並べて照合するまで、
> そのモデルで設計しない。** モックの面ラベル「XIAO」が鏡文字に見えたら、裏（マイク面）を見ている。

## 4. 🔒 XIAO の14本が基板上で何に繋がっているか

📄 出典は wiki に1枚だけ載っている **XIAO ブロックの回路図画像**
（`files.seeedstudio.com/wiki/SenseCAP/respeaker/respeaker_lite_v1.0_sch_1.png`）。
⚠ **Seeed はフル回路図を公開していない。**

🔴 **「ファームで未使用＝空きピン」ではない。基板側の結線を先に見ること。**
D10 をリレー駆動に選んで実機で外した件は、この表があれば起きなかった。

| XIAO | 基板上の行き先 | 空きか |
|---|---|---|
| **D0** | 🔴 `XIAO_WS2812` — RGB LED のデータ線 | ❌ 下記 |
| **D1** | 🔴 `XU316_RST` — XMOS のリセット | ❌ |
| **D2** | `XIAO_D2` → 外部パッド1 ⑬ | ✅ |
| **D3** | `XIAO_D3` → 外部パッド1 ⑬ | ✅ |
| D4 | `I2C_SDA`（**4.7kΩ プルアップ実装済み** R34） | I2C |
| D5 | `I2C_SCL`（**4.7kΩ プルアップ実装済み** R35） | I2C |
| D6 | `I2S_DIN_SEC`（DIN・R36 0Ω） | ❌ |
| D7 | `I2S_DIN_XIAO`（DOUT・R40 0Ω） | ❌ |
| D8 | `I2S_LRCK`（R39 0Ω） | ❌ |
| D9 | `I2S_BCLK`（R38 0Ω） | ❌ |
| **D10** | `I2S_MCLK`（R37 0Ω） | ❌ **実測 1.49V（矩形波の平均）と一致** |
| 3V3 / GND | 基板の 3V3 / GND | — |
| **5V** | 🔒 **`+5V` ネットに直結**（C59 100nF が付くだけ。逆流防止も分離も無い） | 給電の入り口 |

### 🔒 D0 は壊れていない。**680Ωでプルアップされている**

```
XIAO D0 ──[D11 ショットキー]──┬──[R75 680Ω]── +3V3
                              │
XU316 ────[D12 ショットキー]──┴──[Q5 LBSS138 レベルシフタ]──[R69 5.1k→+5V]── WS2812 の DI
```

**XIAO と XMOS が1本の LED データ線をワイヤードOR で共有していて、High を作っているのは
R75 の 680Ω である。**「何も繋がない状態でテスター(10MΩ)を当てても3.3Vが動かない」という実測は、
**このプルアップそのもの**である。🔒 **故障説は否定された。**

⚠ **ただし空きピンにはならない。** 使えば RGB LED のデータが壊れ、XMOS 側も同じ線を叩く。
⬜ RGB LED を捨てる前提なら入力として使える可能性はあるが、XMOS が叩く分をファームで無視できるかが
未検討。**いま結論を出さない。**

| 穴 | 左から | 上下 | 径 |

## 6. 🔒 設計に効くこと

**5.5／5.6 から機械的に出てくる結論。迷ったらここへ戻る。**

1. **両方の短辺と、上辺の右角が塞げない。** 右端にジャックの筒とスピーカーの線、左端に XIAO の
   USB-C、**上辺の右角（X76〜88）に USB-C が上向きに開く**
2. **下辺の占有**: X0〜14 スイッチ ／ X32〜65 中央領域（下端まで）／ X68〜83 ジャック。
   **素の基板を下辺で掴めるのは X20〜32 の間だけ**（マージン込みで X21.5〜31 の約10mm）
3. **XIAO面は一切押さえられない**（ピンヘッダー2列＋ワイヤー、高さ10mm）
4. **マイクは長辺方向の両端寄りに1個ずつ。** マイク面を受けるなら中央だけ。端は開ける
5. → **基板は立てる。** マイク面＝前（マイクが人を向く）／XIAO面＝後ろ（ヘッダーと線は背面へ）
6. → **受け（橋）は X21.5〜31 の1個だけにして、他は全部開放する。** 当たれる物を1個にすれば、
   当たりの原因も1個になる。X合わせは手探りにせず**左端ストッパー**に突き当てる
7. **中央領域を掴む・挟む設計は、面ごとの振り分け（⚠）を測るまで作らない**
8. **隅の穴（左2.492／上2.430・φ2.20）は、左を掴むための本命。** φ2.2あれば**φ2.0のダボが
   立てられる**ので、ネジを使わずに位置を出せる。下側の穴（左60.202／下2.657）は基板を沈めた
   時点で使えない。⚠ **樹脂にネジは切らない**（レジン①は経時で脆い）
9. **左を掴むなら相手はマイク面。** XIAO面は8項のとおり触れないが、マイク面は基板全体で6部品しか
   載っておらず、**左から13.6〜39.9 は全高が無地**、**左から0〜20 × 下から19.5〜34 も無地**。
   マイク U4（左から4.16〜6.81・下から15.25〜18.75）とスイッチ2つ（下から4.1〜7.4）だけ避ければよい

## 7. この機体で足されている物

**公式の図には無い。この機体固有。ここを設計から落とすと前回の事故と同じになる。**

| 物 | 場所 | 効くこと |
|---|---|---|
| **ピンヘッダー 7本 × 2列 ＋ ワイヤー** | XIAO面・XIAO のパッド列から立つ | ⚠ **最も高い（10mm）。XIAO面には何も被せられない** |
