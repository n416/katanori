# 筐体 v6.1n（ナイロン・一体シェル版）

2026-09-15 起こし。`hardware/case_v6_1n.scad`。レジン版の `hardware/case_v6_1.scad` は触らない。
両方を直すときは手で運ぶこと。

## 1. なぜ形が違うのか

v6.1（レジン）が板 6 枚なのは、**寝かせて刷る・反る・支柱の跡を面に出さない**の 3 つが理由だった。
MJF（粉の中で焼く）ではその 3 つが消えるので、**床＋4 壁を 1 部品、天板だけ蓋**にした。

中身を入れる口は上の 1 か所だけでよい。ReSpeaker と PCB はどちらも幅 82.02 で、箱の内寸との
余裕が左右合わせて 1.43mm しかなく、**上下からしか入らない**ため。

つまみ・スピーカー・会話ボタンの小組は今までどおり天板の上で完結する（深さ 50 の箱の底から
工具を入れる作業にしない）。だから天面が蓋である必要がある。

## 2. 刷り分け

| 部品 | 材料 | 体積 | 理由 |
|---|---|---|---|
| シェル（床＋4 壁） | MJF PA12 | 29.54cm³ | 大きい・反りと支柱が問題になる |
| 天板 | MJF PA12 | 13.73cm³ | 同上 |
| スピーカーのバスタブ | MJF PA12 | ― | 小物だが公差は六角だけ |
| 会話ボタンの押し子・バスタブ | MJF PA12 | ― | 動く嵌めは片側 0.40 ＝ 直径 0.80 で MJF の下限 0.76 を満たす |
| つまみ一式（島・つまみ・軸） | **レジン**（自分の機械） | 4.91cm³ | **E リングの溝**が MJF の公差に耐えない |

MJF の 2 大部品で **43.3cm³ ≈ 44g**。レジンの 6 枚は 61.3cm³ ≈ 67g だった。

## 3. MJF の数字（JLC3DP）

| | 値 | この設計での扱い |
|---|---|---|
| 最小肉厚 | 1.0mm | 板は全面 **1.6**（公差 ±0.3 で薄い側へ振れても 1.3） |
| 公差 | ±0.3mm（100mm 以内） | 下の嵌め合いに全部これを積む |
| 穴の公差 | ±0.3mm | 六角ポケットは 呼び ＋0.5 |
| 組む隙間 | 0.76mm 以上 | `FIT_SLIP` 0.1 → **0.8**・`FIT_BURN` 0.4 → **0**（初層が無い） |

刻印は彫り 1.0 → **0.35**（壁 1.6 に対し残り 1.25）。

## 4. レジン版との差分（一覧）

- 板を留めるための物を全部削除: 下の柱 4 本・耳 6 個・ハッチの足・床の座ぐり 5 か所。
  残るのは**天板を留める上の柱 4 本**だけ（筐体のねじ 9 本 → 4 本）
- 背面に**トグルの座** φ14 × 1.8（板 1.6 と合わせて 3.4）。M6 のナットは外側
- 右の壁の内面を 0.8 外へ（`RIGHT_CL` −1.2 → −0.4）。XIAO の USB-C の殻は壁の内面より 1.22 外へ
  出るので、ReSpeaker を右へ寄せて降ろしてから左へ入れる道を作った
- `xusb_shell_relief`（壁を上から降ろすとき殻が通る道）を削除。シェルでは壁が降りて来ない
- つまみ: **E リング 2 枚**（溝 0.95 → 1.90・径 6.0 → 5.85）
- 格子・支柱・ラフトは無し
