## 4. 手でやる作業

| 何を | どこ | メモ |
|---|---|---|
| ハブに足付きの部品 8 個をはんだ付け | J1・J2・J4〜J7・J10（裏）・SW2 | J10 は板の裏。極性は [PCB-V61.md](PCB-V61.md) 8 章 |
| XIAO のライザーに表面実装のメス 2 個をはんだ付け | 表 | パッドは互い違い。電源の列の真ん中の足だけ下向き |
| XIAO のライザーに L 字のメス 1x7 をはんだ付け | 裏 | 胴と板の間にはがき 2 枚を挟んだまま。固まったら抜いてもよい |
| OLED のライザーに縦のメス 1x4 と L 字のメス 1x4 をはんだ付け | 表・裏 | はがきは挟まない（板厚 1.6） |
| 線を 4 本作る | 机の上 | 板の側を圧着して殻に入れる。切る長さはマニュアル手順 0 |
| 直はんだ 3 か所 | スピーカーのリード・マイクロスイッチの C と NO・リードスイッチの足 | マニュアル手順 1 |
| 磁石を接着 | つまみの軸の先 | |
| 軸のガイドを PCB に付ける | PCB の上・U4 に被せる | PCB を箱に入れる前に、机の上で。下の口を U4 に被せて位置を決め、足を M2 × 8 とナットで押さえる |
| 電源の押しボタンのキャップを刷る | 光造形 | 2 章 |
| 組み立て | | マニュアル手順 0〜 |
