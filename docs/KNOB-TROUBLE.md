## いま分かっている中で一番強い事実（2026-07-30）

**コーデックが死ぬのは、つまみを回している最中。スイッチが開くより前。**

```
[+ 45.3s] creg 正常 (0x3F=0xD4 / P1 0x09=0x3C)
[+ 53.2s] [CODEC] !! リセットを検出しました      <- 死んだ
[+ 58.1s] [KNOB] OFF位置                        <- スイッチが開いたのは 4.9秒“後”
[+ 63.1s] [NET] Wi-Fiを切断しました
[+ 64.1s] [KNOB] ON位置
```

これで**ソフトの経路は完全に消える**。会話終了・画面消灯・通信停止はどれも
スイッチのOFF検出より後に走るので、死んだ時点ではまだ何も動いていない。
`knobdis` で読み取りを止めても起きる、という以前の観察とも一致する。

残っているのは「**回す**」という物理動作そのもの。ファームの `[CODEC]` メッセージが
言うとおり、回すことで3.3Vが瞬断している線が濃い。**振動で一瞬どこかが繋がる**
という筋なら、半田をやり直しても再発することと辻褄が合う。

→ 対策は下の **3V3線への1kΩ直列**。「候補」ではなく入れるべきもの。
根治は **AS5600（非接触）への移行**（[KNOB-ENCODER.md](KNOB-ENCODER.md)）。

## 症状

つまみを回すと、コーデックの出力が死んで音が出なくなる。

- ESP32を再起動しても戻らない（`reboot` でも、ファームを書き込み直しても）
- **USBを抜き差しすると戻る**
- 数秒で自力復帰することもある

## 確かめた事実（2026-07-29）

ここは信用してよい。

- **ファームウェアは無関係。** `knobdis` でつまみの読み取りを完全に止めた状態でも発生する
- `low 1`（GPIO2を300ms LOWにする）では発生しない。**信号レベルの問題ではない**
- `wifioff` → `wifi` を繰り返しても発生しない。Wi-Fi再接続の突入電流ではない
- **`creg` が正常値でも音が出ないことがある。** 生死の判定材料としては不十分

異常時のレジスタは2パターン出た。

| | `0x1B` | `0x3F`(DAC電源) | `P1 0x09`(出力ドライバ) |
|---|---|---|---|
| 正常 | 0x30 | 0xD4 | 0x3C |
| 異常パターン1 | **0x00** | 0x14 | 0x00 |
| 異常パターン2 | 0x30 | 0x14 | 0x00 |

パターン1は全部が初期値で、コーデックのリセットに見える。

> **追記（2026-07-30）**: パターン1は 2026-07-30 の再現でも出た（上の一番強い事実）。
> 一時「`WIFI_OFF` でも再現する」と書いたが**誤り**。`WIFI_OFF` を15秒保持しても
> パターン1にはならない（`wifistop` で単独試験済み）。詳細は [TODO.md](TODO.md) 2.5。
パターン2は `0x1B` が残っているので**誰かがI2Cで意図的に落としている**。
ESP32は `0x40`/`0x41`/`0x42` しか書かないので、XMOSの仕業ということになる。

## 外れた仮説

もう追わなくてよい。

| 仮説 | 否定した根拠 |
|---|---|
| D1(GPIO2)がReSpeaker側のリセット線 | `low 1` でLOWに落としても無傷 |
| Wi-Fi再接続の突入電流で3.3Vが落ちる | `wifioff`→`wifi` を繰り返しても再現せず |
| 3V3がスイッチ接点へ漏れている | 3V3線を外しても発生（1回目は無事、2回目に発生） |

## この調査の失敗

**各条件を1回ずつしか試さず、そのたびに結論を出していた。** 間欠故障なので、
1回の成功は何の証拠にもならない。実際、「3V3を外せば起きない」と判断した直後に、
同じ条件の2回目で発生した。次は回数を数える。

## 再発の記録

- **2026-07-30**: 配線修理（D0/D1入れ替え）とカーブ実測でつまみを何十回も回した日に
  再発。レジスタは異常パターン1。USB抜き差しで復旧。配線を正しても起きるので、
  D0/D1の取り違えとは無関係（切り分け済みの結論どおり）。
- 同日の教訓: 「音が出ない」の切り分けは、まず**つまみ位置とビープ振幅の掛け算**を
  疑うこと。`beep2` の振幅は 4000/32767（12%）しかなく、つまみ12時（ゲイン0.14）だと
  実効1.7%でほぼ聞こえない。起動音（ほぼフルスケール）が聞こえるのに `beep2` が
  聞こえない場合は、故障ではなく音量。

## 分かっている回避策

**スイッチの2本を外しておけば、音量つまみとしては使える。** 失うのはOFF機能だけ。

## 対策（次にやること）

回している最中に死ぬ＝物理側なので、これは「候補」ではなく**入れるべきもの**。

**3V3の線に1kΩを直列に入れる。**

```
3V3 ──[1kΩ]── つまみの足 ──…── GND
```

どこかが短絡しても電流が3.3mAに制限され、電源が落ちない。

入れたら `pumpVolumeKnob()`（main.cpp）のADC換算（`3960` の係数）を直すこと。
つまみの上端が3.0V付近に下がるため。
