# つまみのエンコーダ化（熱で壊れない構成・案B）

可変抵抗（RV121SF）の後継。動機は [KNOB-TROUBLE.md](KNOB-TROUBLE.md) と
2026-07-30 の実測で判明した抵抗膜の熱劣化（カーブが3時で22%まで歪んだ）。
**カーボン抵抗膜を使う部品をやめ、熱で劣化する要素をゼロにする。**

状態: **AS5600モジュールで確定・発注段階**（2026-07-30。Amazon「Hailege 2個セット
マグネット付き」¥990）。現行の可変抵抗+実測テーブル（main.cpp の `kKnobCurve`）も
実用にはなっているので、移行までは現状のまま使える。

Amazonの検索結果の罠: **「3ピンワイヤー付き・ジンバルモーター用」の安い基板
（¥500台）は買わない**。コネクタに出ているのがPWM/アナログ出力で、I2C(SDA/SCL)が
ピンに出ていない。ピンヘッダにSDA/SCLが明記されたブレイクアウト形を選ぶ。

## 移行するもう一つの理由（2026-07-30 実測）

コーデックが死ぬのは**つまみを回している最中**で、連動スイッチが開く4.9秒前
（[KNOB-TROUBLE.md](KNOB-TROUBLE.md)）。半田をやり直しても再発する。原因は特定
できていないが、**回すという物理動作**に紐づいていることだけは確か。

AS5600なら回るのは磁石だけで、基板も配線も静止したまま。**連動スイッチの2本も
無くなる**（OFFは角度の閾値で判定できる）ので、一番疑われていた配線ごと消える。
原因を特定しないまま症状を消せる、という点でも移行の価値が上がった。

> ⚠ **可変抵抗向けの対策「3V3線に1kΩ直列」はAS5600には使えない。**
> 10kΩの分圧なら0.33mAなので1kΩ挟んでも0.33Vしか落ちないが、AS5600は6.5mA食う
> ので1kΩでは6.5V落ちて動かない。AS5600側の保護は3V3のバルクコンデンサか配線の
> 作り込みで考えること。

> ⚠ **AS5600はOLED・コーデックと同じI2Cバスに乗る。** アドレスは衝突しない
> （0x36 / 0x3C / 0x18）が、配線が不安定だとバスごと道連れになる。組んだら
> **20回以上回して** `creg` と `[CODEC]` ログを見ること。1回で判断しない。

## 構成

| 役割 | 現行（可変抵抗） | 新（エンコーダ） |
|---|---|---|
| 音量の入力 | カーボン膜の分圧をADCで読む | EC11の2相パルスを数える（金属接点のみ） |
| 音量の記憶 | 軸の角度そのもの | NVSに保存（回転停止2秒後に書く。フラッシュ摩耗対策） |
| 音量の表示 | 軸の向きを見る | 回した瞬間にOLEDへ音量バーを出す |
| OFFのカチッ（手応え） | スイッチ内蔵デテント | 3Dプリントの溝+板バネデテント（機械的な感触だけ） |
| OFFの検知（電気） | SPSTスイッチ | **磁石+リードスイッチ（ガラス封止接点・磁石で開閉）** |
| 回転の壁 | 内蔵（270度） | つまみのピン+パネル側の270度溝 |

**マイクロスイッチ案（境目でパルス）は不採用。** 接点の摩耗が残るのと、
パルス読み逃しの補正ロジックが要るため。ホールICなら「OFF領域に居る間ずっと
検知」で、ファームは現行の `knobOff` と同じ単純な形のまま。

## 近道: 既製品の非接触ポテンショメータ

「摩耗しない可変抵抗が欲しい」という欲求は業界共通で、**ホール式ポテンショメータ**
として製品化されている（車のアクセルペダル等）。こちらを使うと下のエンコーダ構成より
さらに単純になる。**絶対角度が読める**ので:

- 軸の向き＝音量。現行UXそのまま（OLEDの音量バー不要・NVS保存不要）
- 「回し切ってOFF」は角度の閾値をソフトで切るだけ（OFF検知の磁石もICも不要）
- カチッの手応えだけ3Dプリントのデテントで作る

| 入手経路 | 例 | 目安 |
|---|---|---|
| 軸付き完成品（通販） | Bourns AMS22 / Piher PST / P3022系 | ¥1,500前後〜 |
| チップ+自作軸 | **AS5600 モジュール**（I2C、磁石は軸端に固定） | ¥300〜500 |

AS5600 は I2C（アドレス0x36。OLED 0x3C・コーデック0x18 と衝突しない）で、
軸受けと磁石の同芯だけ3Dプリント側で精度を出す必要がある。
**軸付き完成品が入手できるならそれが最小工作。** エンコーダ構成（下）は
秋葉原で当日揃えたい場合の代替。

**Amazonで買うならAS5600モジュールが本命**（2026-07-30 決定）。検索「AS5600
モジュール」で¥500〜1,000。**磁石付属品を選ぶ**こと（径方向磁化の専用磁石が
必要で、単品調達は面倒）。ノーブランド品はハズレ混在のため2個買って選別する。
はんだ付けはピンヘッダ4本（VCC/GND/SDA/SCL）のみ。

## 部品（型番リスト・在庫確認 2026-07-30）

| 品目 | 型番 | 秋月販売コード | 数 | 単価 |
|---|---|---|---|---|
| ロータリーエンコーダ（24クリック・Dシャフト12mm） | **EC12E2420801** | **106357** | 2 | ¥100 |
| リードスイッチ（OFF検知。φ1.8×10mmガラス管） | **MKA-10110** | **103676** | 2 | ¥290 |
| ネオジム磁石 φ3〜5mm | 秋月に定番なし。**千石かダイソー**で | 1パック | 〜¥300 |

- リードスイッチは**磁石が近づくと閉じるA接点**。今のつまみスイッチと同じ
  GPIO+GNDの2線で読めて、給電も極性合わせも不要。閉じる論理が現行と逆
  （OFF位置で閉）なので、既存のビルドフラグ `KATANORI_KNOB_SW_INVERT=1` を使う
- ガラス管は曲げ・切りに弱い。足を曲げるときは管の根元をつかんで曲げる
- **買ってはいけない**: ホールIC UH277G（¥30・販売コード111031）は交番検知
  （ラッチ型）で、磁石1個の近接検知には使えない
- 代替: ホールIC **TCS40DPR**（販売コード118309・5個入¥100・両極検知で極性不問）。
  ただしSOT23F(2.9mm)の表面実装なので変換基板と細かい半田付けが要る。
  リードスイッチが入手できないときの控え

追加の基板・線材は手持ちの常備品でよい。

## 機構（3Dプリント）

- つまみ: φ25mm前後。内側に (1) 磁石ポケット (2) 回転制限ピン (3) デテント用の山
- パネル片: エンコーダをナットで固定する座 + 270度の溝 + 板バネ（プリント一体の
  片持ち梁。OFF境界の谷に落ちて「カチッ」の感触を作る）+ リードスイッチの座
- **寸法は筐体側の条件（パネル厚・つまみ周りの空間）が決まってから。**
  現行筐体は段ボールなので、EC11のナット固定には小さな板（ユニバーサル基板の
  切れ端かプリント板）を挟む

## ファーム（未着手・移行時に書く）

- A/B相は現行の D0/D1 を流用（INPUT_PULLUP・共通端子はGND）。リードスイッチは
  空きピン1本+GND（給電不要。`KATANORI_KNOB_SW_INVERT=1` で論理反転）
- クォドラチャデコード → 1クリックで±0.3dB×4 相当。NVSへは回転が止まって
  2秒後に保存
- OFF検知は現行 `knobOff` の読み替えのみ。`kKnobCurve`・ADC関連は全部消える
- 音量バーのOLED表示を追加（エンコーダは軸の向きに意味がないため必須）
