# つまみのエンコーダ化（熱で壊れない構成・案B）

可変抵抗（RV121SF）の後継。動機は [KNOB-TROUBLE.md](KNOB-TROUBLE.md) と
2026-07-30 の実測で判明した抵抗膜の熱劣化（カーブが3時で22%まで歪んだ）。
**カーボン抵抗膜を使う部品をやめ、熱で劣化する要素をゼロにする。**

状態: **設計段階。部品未購入。** 現行の可変抵抗+実測テーブル（main.cpp の
`kKnobCurve`）が実用になっているため、急ぎではない。効きが変わってきたら移行する。

## 構成

| 役割 | 現行（可変抵抗） | 新（エンコーダ） |
|---|---|---|
| 音量の入力 | カーボン膜の分圧をADCで読む | EC11の2相パルスを数える（金属接点のみ） |
| 音量の記憶 | 軸の角度そのもの | NVSに保存（回転停止2秒後に書く。フラッシュ摩耗対策） |
| 音量の表示 | 軸の向きを見る | 回した瞬間にOLEDへ音量バーを出す |
| OFFのカチッ（手応え） | スイッチ内蔵デテント | 3Dプリントの溝+板バネデテント（機械的な感触だけ） |
| OFFの検知（電気） | SPSTスイッチ | **磁石+ホールIC（非接触・摩耗ゼロ）** |
| 回転の壁 | 内蔵（270度） | つまみのピン+パネル側の270度溝 |

**マイクロスイッチ案（境目でパルス）は不採用。** 接点の摩耗が残るのと、
パルス読み逃しの補正ロジックが要るため。ホールICなら「OFF領域に居る間ずっと
検知」で、ファームは現行の `knobOff` と同じ単純な形のまま。

## 近道: 既製品の非接触ポテンショメータ

「摩耗しない可変抵抗が欲しい」という欲求は業界共通で、**ホール式ポテンショメータ**
として製品化されている（車のアクセルペダル等）。こちらを使うと下のエンコーダ構成より
さらに単純になる。**絶対角度が読める**ので:

- 軸の向き＝音量。現行UXそのまま（OLEDの音量バー不要・NVS保存不要）
- 「回し切ってOFF」は角度の閾値をソフトで切るだけ（OFF検知の磁石もICも不要）
- カチッの手応えだけ3Dプリントのデテントで作る

| 入手経路 | 例 | 目安 |
|---|---|---|
| 軸付き完成品（通販） | Bourns AMS22 / Piher PST / P3022系 | ¥1,500前後〜 |
| チップ+自作軸 | **AS5600 モジュール**（I2C、磁石は軸端に固定） | ¥300〜500 |

AS5600 は I2C（アドレス0x36。OLED 0x3C・コーデック0x18 と衝突しない）で、
軸受けと磁石の同芯だけ3Dプリント側で精度を出す必要がある。
**軸付き完成品が入手できるならそれが最小工作。** エンコーダ構成（下）は
秋葉原で当日揃えたい場合の代替。

## 部品（秋葉原・数百円）

- [ ] **EC11系ロータリーエンコーダ**（24クリック/回転・軸長15〜20mm） … 2個 / 各¥100前後
  - 1クリック≒4%刻み。押しスイッチ付きでも値段が変わらないので付きを買う（将来の予備入力）
- [ ] **ホールIC**（TO-92形状・デジタル出力・A3144互換など） … 2個 / 各¥50前後
  - TO-92なのは半田付けが楽なため（SOT-23の低消費品 DRV5032 は熱に強い人向け）
  - 消費電流5mA級だが、**VCCをGPIOから給電して読む瞬間だけONにする**ので実質µA
- [ ] **ネオジム磁石 φ3×2mm程度** … 1パック / ¥100〜200
  - つまみ側に埋める。極性はホールICの検知面に合わせる（買ったら先に卓上で確認）

追加の基板・線材は手持ちの常備品でよい。

## 機構（3Dプリント）

- つまみ: φ25mm前後。内側に (1) 磁石ポケット (2) 回転制限ピン (3) デテント用の山
- パネル片: EC11をM7ナットで固定する座 + 270度の溝 + 板バネ（プリント一体の
  片持ち梁。OFF境界の谷に落ちて「カチッ」の感触を作る）+ ホールICの座
- **寸法は筐体側の条件（パネル厚・つまみ周りの空間）が決まってから。**
  現行筐体は段ボールなので、EC11のナット固定には小さな板（ユニバーサル基板の
  切れ端かプリント板）を挟む

## ファーム（未着手・移行時に書く）

- A/B相は現行の D0/D1 を流用（INPUT_PULLUP・共通端子はGND）。ホールICの
  出力と給電GPIOの2本は空きピンから割り当てる（実装時に確認）
- クォドラチャデコード → 1クリックで±0.3dB×4 相当。NVSへは回転が止まって
  2秒後に保存
- OFF検知は現行 `knobOff` の読み替えのみ。`kKnobCurve`・ADC関連は全部消える
- 音量バーのOLED表示を追加（エンコーダは軸の向きに意味がないため必須）
