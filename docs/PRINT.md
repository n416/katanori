## 手順（この順で。飛ばさない）

### 0. LCDの生存確認 ← **最優先。ここが通らなければ他は全部無意味**

モノクロLCDは消耗品で、寿命は2000時間前後。**譲り受けた個体は残り寿命が不明。**

1. **レジンバットを外す**（レジンは入れない）
2. 本体メニューの露光テスト機能で**画面全体を光らせる**
3. **ドット抜け・ムラ・暗い領域**が無いか見る

ここで異常があれば、LCDの交換（数千円）から始まる。**レベリングや露光テストを
先にやっても無駄になる。**

⚠ 直視しない。UV光。

#### 結果（2026-08-01）: **合格**

| 項目 | 結果 |
|---|---|
| 起動 | OK |
| LCD点灯 | 全面点灯。暗室で部屋が照らされるほど明るい |
| 欠け線・ドット抜けの塊 | 無し |
| 細かいムラ | **判定保留** |

**LCDは生きている。** 細かいムラは写真では判定できなかった（暗室だとカメラの露出が
飽和して真っ青に飛ぶ。明室だと室内光の映り込みで隠れる）。**段階4の露光テストモデルで
「特定の場所だけ薄い」という形で出るので、そこで拾う。**

### 1. 機構の確認

- Zリードスクリューが**引っかかりなく上下**するか
- ビルドプレートに**固まったレジンの残り**が付いていないか
- レジンバットの**FEPの状態** — 白濁・傷・たるみ。指で弾いて太鼓のような音がするか
- FEPが怪しければ**先に張り替える**（予備あり・張り替え方は教わっている）

#### 結果（2026-08-01）: **合格**

| 項目 | 結果 |
|---|---|
| プレートの固着レジン | 無し |
| バット内の固着レジン | 無し |
| FEPの白濁・キズ | 無し |
| FEPの張り（指で弾く） | 「ポン」＝張りあり。**張り替え不要** |
| Z軸の上下 | スムーズ。異音・引っかかり無し |

**前の持ち主はレジンを残さず片付けていた。** FEPも生きているので張り替えずに進む。

### 2. ビルドプレートのレベリング

光造形の失敗のほとんどはここ。**レジンを入れる前**に済ませる。

手順: バットを外したままLCDにA4用紙を1枚敷く → プレートを付けて固定ノブを締める →
調整ネジ4本を緩める → 原点復帰 → プレートを均等に押さえながら対角の順にネジを締める →
紙が「軽い抵抗つきで抜ける」ことを確認 → **メニューで Z=0 を設定**。

⚠ **Z=0 の設定を忘れると調整が全部消える。**

#### 結果（2026-08-01）: **完了**

### 3. 水洗いレジンで機械の操作を覚える

**いきなり本番レジン（Ultra高靭性白）を使わない。** 失敗の後片付けが水で済むほうで、
一連の流れ（注ぐ→刷る→外す→洗う→二次硬化→バットを片付ける）を1回通す。

付属のテストモデルは**入っていなかった**（USBは前の持ち主のミニチュアのみ）。
代わりに自作のテストモデルを使う（下の「1回目のテストモデル」）。

#### 結果（2026-08-01 深夜）: **成功**

| 項目 | 結果 |
|---|---|
| レジン | ①水洗い灰。よく振ってから注いだ |
| バットの液面 | 底から10mm（**4mmの造形物に対して余裕を6mm残す**） |
| 層厚 / 通常露光 / ボトム露光 / ボトム層数 | 0.05mm / 2.5s / 35s / 5層 |
| 見積り時間 → 実測 | 15分1秒 → **20分** |
| プレートへの食いつき | **成功**（造形物がプレートに付いた） |

**時間の換算: この機体は CHITUBOX の見積り × 1.3 が実測。** 大物の予定を立てるときに使う。

造形の結果:

| 部品 | 結果 |
|---|---|
| 20mm角の板 | 角がシャープ。反り・層ズレ・欠けなし |
| リング（内径 2.0 / 3.0 / 6.0） | **3つとも穴が開通**。内径2.0mmでも塞がらない |
| 薄壁（0.3 / 0.5 / 1.0） | 3枚とも造形された。**0.3mmが形になる** |
| ピン（Φ1.0 / 1.5 / 2.0 / 3.0） | **3本のみ。1本欠け**（おそらく最細のΦ1.0が剥離に負けた） |

欠けた1本は、バットを濾しても・プレートにも・洗浄水にも見つからなかった。
**FEPは目視で異常なし**（濾したあと確認済み）。剥がすときに飛んだ可能性が高い。

**現物合わせの結果: 内径6.00mmのリングにAS5600の磁石を入れたら「ブカブカ」。**
磁石は6mmではない（[KNOB-ENCODER.md](KNOB-ENCODER.md) に記録）。

**数値の測定はノギス待ち。** 段階4はここから。

⚠ **金属ヘラはビルドプレートに使ってよいが、FEPには絶対に使わない。**
混同を避けるため、**プレートを外してから**造形物を剥がす手順にする。

⚠ **洗った水は排水に流さない。** 「水洗い」は水で洗える意味で、流せる意味ではない。
洗い水は容器のまま日光に当ててレジンを硬化・沈殿させ、沈殿物を可燃ゴミにする。

### 4. 露光時間を出す（本番レジン）

**ここが「設定」の本体。** 露光時間はレジンとプリンタの組み合わせごとの実測値で、
ネットの数字は出発点にしかならない。

露光テスト用のモデル（Cones of Calibration / AmeraLabs Town / XP2 Validation Matrix
など、無料で配布されているもの）を刷って詰める。

出発点の目安（**あくまで出発点。実測で置き換える**）:

| 項目 | 目安 |
|---|---|
| 層厚 | 0.05mm |
| 通常露光 | 2.0〜3.0秒 |
| ボトム露光 | 30〜40秒 |
| ボトム層数 | 4〜6層 |

**高靭性レジンは標準レジンより長めに要ることが多い。**

**約1年9ヶ月経っている。** 顔料が底に固着している可能性がある。

## 2回目: 磁石ポケット＋板バネのゲージ（次に刷るもの）

**刷るのは [../hardware/print-run-2.stl](../hardware/print-run-2.stl)**

2つのゲージが1枚のSTLに入っている。92 × 39 × 3mm・見積り13分（実測17分前後）。
サポート不要・プレート直置き。

### (1) 磁石ポケットのゲージ

[../hardware/magnet-fit-gauge.stl](../hardware/magnet-fit-gauge.stl)
（生成スクリプト: [../hardware/gen_magnet_gauge.py](../hardware/gen_magnet_gauge.py)）

内径 **3.8 / 3.9 / 4.0 / 4.1 / 4.2 / 4.3 / 4.4 / 4.5mm** のリング8個。

**8個は桟で1枚につながっている。** 1回目でピンを1本紛失したので、バラバラの
小部品にしない。桟は穴の縁から 0.35mm 逃がした位置に通してあり、穴を塞がない。
高さもリング（3.0mm）より低い 1.5mm なので、切り離したければニッパーで切れる。

**磁石が「少し力を入れると入り、ガタつかない」最小のリングの内径が、
そのままホルダーのポケットの設計値になる。**

これが効くのは、**ホルダーの設計に要るのが磁石の絶対径ではないから**。
必要なのは「どの設計値で穴を作れば刷ったときにこの磁石が嵌まるか」で、
それは磁石の公差と樹脂の縮みの**両方を含んだ値**でなければ意味がない。
ノギスで磁石だけを測っても、そこから縮み量を推定する一手間が残る。

桟に並んだ順が内径の順。**外径も内径と一緒に大きくしてある**ので、桟を切り離した
あとでも大小に並べ直せば順番が復元できる。

### (2) 板バネ（片持ち梁）のゲージ

厚み **0.4 / 0.6 / 0.8mm** × 長さ **12 / 18 / 24mm** の **9枚**。根元は桟で固定。
並びは左から「0.4の短中長 / 0.6の短中長 / 0.8の短中長」で、長さの短中長が3回
くり返すので、その切れ目が厚みの境目になる。

**1回目の結果（8mmの短冊が「折れないが戻らない」）を受けた再試験。**
原因の候補が2つあるうち、**今回はレジン①のままなので、切り分けられるのは
形状（長さ）だけ**。それでも:

- 長い梁が**戻る** → 原因は形状だった。本番レジンならさらに良くなる
- 長い梁も**戻らない** → 原因は材料。レジン②か金属（リン青銅片）へ進む

と2つの仮説が切り分けられる（[KNOB-TROUBLE.md](KNOB-TROUBLE.md) の
「一度に1つしか変えない」に沿う）。

1回目との違いは**支持条件**。1回目はただの短冊を指で曲げただけで根元が固定されて
いなかった。今回は**根元を桟に固定した本物の片持ち梁**にしてある。

⚠ **刃は寝かせず「立てて」ある**（厚みが水平方向）。厚みをZに取ると、ボトム層
（35秒露光の5層＝0.25mm）が刃の大部分を占めてしまい、**過硬化した層の硬さを
測ることになる**。立てれば刃はどの高さも同じ露光で焼かれる。
