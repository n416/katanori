## 2. スピーカー

- [ ] **8Ω 1〜3W の小型スピーカー** … 1〜2個

| 条件 | 理由 |

| **8Ω**（4Ωは避ける） | 4Ωだと同じ音量で電流が倍になる。電池が半分の時間で終わる |

## 4. 電源（余裕を持たせて選ぶ）

消費電流は推定300〜450mA（XMOSの実測値が非公開のため不確定）。
**余裕を持たせておけば、測定結果が変わっても買い直しにならない。**

- [x] **Adafruit PowerBoost 1000C**（入手済み）… 昇圧・充電・パススルーが1枚で片付く
  - 出力5V / **連続1000mA+**（内部スイッチ2A・ピーク制限約2.5A）。当初は「2A以上」を
    求めていたが、これは**実測前の安全側の要求**。推定300〜450mAなら足りる計算で、
    **消費電流の実測が出るまでは仮確定**とする（足りなければ昇圧だけ別に積む）
  - `EN` ピンが出ている（つまみOFFのEN制御・マスタースイッチの両方がここに繋がる）
  - `LBO` ピンが出ている（電池残量の取得がGPIO 1本で済む）
  - ピンの詳細と⚠**EN制御の自己遮断問題**は [POWER.md](POWER.md)
- [x] **リポ電池 3.7V 1000mAh**（入手済み）
  - **容量はまだ確定ではない。** 稼働時間の見積もり（1000mAhで会話1.5時間など）は
    推定消費電流の上に乗った推定でしかなく、XMOSの実測もアンプを動かした実績も無い
  - 1000mAhで約20g。**軽い方から始めれば、重いと感じたとき電池のせいか筐体のせいか
    切り分けられる。** 実測後に足りなければ容量を上げて買い足す
- [x] ~~リチウムイオン充電モジュール~~ … **PowerBoost 1000C に内蔵**（MCP73871・最大1A）

### マスタースイッチ（完全遮断用）

- [x] **トグルスイッチ MTS-102**（3ピン SPDT ON-ON・6A 125VAC・33×13mm）… 10個入り
  ¥485 / Amazon・2026-07-30 購入。**定格は要求（2A以上）を大きく満たす**

つまみのOFFはEN制御でファームが生きていないと効かず、電池を積むと「USBを抜く」という
最後の手段も消える（ハング時に止める方法が電池切れ待ちになる）。

**入る場所は PowerBoost 1000C の `EN` ⇔ `GND`。** 当初は「電池と昇圧の間の放電経路
（実流約700mA）」を想定して定格2A以上を要求していたが、**PowerBoost では電池のJSTが
充電器と共用**なので、そこを切ると「OFFのまま充電できる」が壊れる。ENなら昇圧だけが
止まり、充電回路は生きたまま残る。詳細は [POWER.md](POWER.md)。

> **この変更で定格は無関係になった**（ENに流れるのは信号レベルのµA。Adafruit も
> 「スイッチは小さくてよい、ただの信号だから」と書いている）。MTS-102 の 6A 125VAC は
> 過剰だが、手元にあるので使う。定格が効くのは接点の信頼性の面だけ。

> ⚠ **MTS-102 は ON-ON で、OFF位置が無い。** 3ピンの真ん中がコモンで、倒した側の
> ピンに繋がる切り替えスイッチ。電源スイッチとして使うときは**コモン＋片側だけを配線し、
> 反対側のピンは未接続にする**（両側を繋ぐと永久にONになる）。倒す向きと通じる側は
> 逆になる（レバーを下げると上側のピンが通じる）ので、パネルのON/OFF表示は現物で確認する。
>
> 機構面: レバー込み全長33mm・胴径13mm・取付は**φ6mmの穴**（M6ブッシング）。肩に載せる
> 筐体では**レバーが服に引っかかる**位置になり得るので、筐体設計で凹ませるか裏面に置く。
> 日常操作はつまみのOFF側なので、こちらは押しにくい場所でよい。

### リードスイッチ（つまみOFFで電源を切る）

- [x] **KILIGEN 樹脂モールド リードスイッチ**（2.5mm×14mm・**常開(N/O)**・
  ラウンドマグネット10個付属）… 10個入り ¥849 / Amazon（品番 E331-10個）・
  **2026-08-01 購入・8/3着**

  付属マグネットは **φ6mm × 厚さ2mm**（商品ページの実寸図。2026-08-02 確認）。

  ⚠ **AS5600の磁石と混同しないこと。** 別物で、互換性はない。

  | 磁石 | 用途 | 着磁の向き | 径 |
  |---|---|---|---|
  | AS5600キット付属 | 角度の検出（軸に乗る） | **径方向着磁**（でないと読めない） | **4〜5mm**（φ4.0濃厚・未実測） |
  | このリードスイッチ付属 | OFF位置で電源を切る | 通常（軸方向） | **φ6 × 2mm** |

  **1回目のテストで刷った内径6.00mmのリングが、この磁石のゲージとして使える**
  （[PRINT.md](PRINT.md)）。AS5600の磁石にはブカブカだったが、こちらには正しい寸法。
  届いたら入れてみて、つまみ側の磁石ポケットの設計値を決める。

**N/O（常開＝磁石が近づくと閉じる）でなければ成立しない。** ENはGNDに落ちたときに
止まるので「OFF位置で閉じる」向きが要る。N/C（常閉）だと、OFF位置**以外の全域**に
磁石を効かせ続ける機構が必要になり、つまみ1個では作れない。
**同じページに ¥999 のノーマルクローズ版が並んでいるので注意。**

> 感度（AT値）が商品ページに書かれていないのが弱点。**弱い磁石で閉じるほどAS5600への
> 干渉が減る**ので、磁石を強くしないと閉じないようなら、AT値が明記された
> MKA-10110（10-15AT・Amazon ¥466／秋月 103676）へ逃げる。磁石は付属しない。
>
> 故障モードは「開きっぱなし＝電源が切れない」。**並列に入れる非常用トグルが
> その受け皿になる**（トグルを残す理由の一つ）。

**電源がゼロの状態から復帰させる唯一の手段**なので必須（ホールICは電源が要る）。
つまみOFF位置で磁石が近づくと閉じ、`EN`をGNDへ落とす。設計は [POWER.md](POWER.md)。

選ぶときの条件:

| 条件 | 理由 |
|---|---|
| **常開（N/O・ノーマルオープン）** | 磁石が近づくと閉じる向き。NC（常閉）だと論理が逆になる |
| **磁石が付属している** | AS5600付属の径方向着磁マグネットは流用しない（あちらの予備） |
| **数が多い（20個以上）** | 無名ブランドはハズレ混在。配置の試行錯誤にも要る |
| 小型（ガラス管10〜14mm） | つまみ周りに入る |

⚠ **磁石は「小さくて弱い」ほうが良い。** 強い磁石を使うと、軸上のAS5600の角度を
狂わせる（[POWER.md](POWER.md) の干渉の項）。閉じるだけの磁力があれば十分。

⚠ ガラス管は曲げ・切りに弱い。足を曲げるときは**管の根元をつかむ**
（[KNOB-ENCODER.md](KNOB-ENCODER.md) の調査時のメモ）。

### ~~パススルーを自作する場合の部品~~ → 不要になった

PowerBoost 1000C の MCP73871 が**ロードシェアリングを内蔵**しているため、
Pch MOSFET＋ショットキーで自作する必要は無くなった。

（TP4056系の安い充電基板を使う場合の話だった。負荷と電池が並列に繋がるため
パススルーにならず、MOSFETとダイオードを足して解決する定番回路が要る）

  ⚠ **訂正（2026-08-07）: 下の「1枚で足りる」は数え落としがあった。**

  **3V3・GND・SDA・SCL の4本がそれぞれ2箇所へ分岐する＝8接続が1点に集まる**。
  いまブレッドボードで解決しているが、持ち歩く機体には残せない
  （[TODO.md](TODO.md) 2章「持ち歩くと確実に外れる」）。
  → **この基板はリレー駆動だけでなく、電源とI2Cのハブを兼ねる**必要がある。
  ⬜ **板の実寸が分かってから配置を引き直す。**

  秋月Cタイプ（72 × 47mm）なら半分も使わない。
  ⚠ **足りなければ基板は切れる**（穴の列に沿ってカッターで筋を入れて折る）。
  ⬜ 手持ちの実寸は未取得

## 帰ってからの順番

1. スピーカーを繋ぐ（**音量を35%より下げてから**。耳から離して最初の1回）
2. USB電流チェッカーで4場面を測る（起動時・待機・会話中・音量最大）
3. 数字から電池の持ち時間を計算し、容量が足りているか判断
4. テスターで ReSpeaker の電源経路を追う（3.3V直結が可能なら昇圧が不要になる）
5. 静かなタイミングがあれば VAD計測（低域比の検証、10分）
