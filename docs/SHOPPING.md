## 2. スピーカー

- [ ] **8Ω 1〜3W の小型スピーカー** … 1〜2個

| 条件 | 理由 |
|---|---|
| **8Ω**（4Ωは避ける） | 4Ωだと同じ音量で電流が倍になる。電池が半分の時間で終わる |
| 1〜3W | 基板側のアンプは5Wまで。2W前後で十分 |
| 小型・軽量（φ40mm以下） | 肩に載せるので重さが直接効く |
| 薄型 | 筐体の厚みを決めるのがスピーカーになりがち |

**買う前に、ReSpeaker Lite のスピーカー端子を見ておくこと。** コネクタが PH2.0 なら
同じコネクタ付きのスピーカーを選ぶと半田付けが減る。違う場合や裸線の場合は、
下の「コネクタ・線材」でつなぐ。

## 3. 測定器

- [ ] **USB電流チェッカー**（電圧・電流表示） … 1個 / ¥1,000前後

**明日の最優先作業に必要。** ReSpeaker Lite のUSB-Cと電源の間に挟むと、
XIAOも含めた全体の消費が1点で測れる。この数字が出るまで電池容量が確定しない。

USB-C対応のものを選ぶ（USB-Aだと変換が要る）。

---

## 4. 電源（余裕を持たせて選ぶ）

消費電流は推定300〜450mA（XMOSの実測値が非公開のため不確定）。
**余裕を持たせておけば、測定結果が変わっても買い直しにならない。**

- [ ] **昇圧DC-DCモジュール** 出力5V / **2A以上** … 1〜2個
  - 1Aだと起動時の突入電流で不安。2Aあれば最悪でも足りる
- [ ] **リポ電池 3.7V 2000mAh前後**（**保護回路付き**・コネクタ付き） … 1個
  - 容量は稼働時間を決めるだけ。ずれても部品は無駄にならない
  - 2000mAhで約40g。肩に載せる重さの上限を探る意味でもこのあたり
- [ ] **リチウムイオン充電モジュール**（充電電流1A程度） … 1個
  - **パススルー（充電しながら使える）対応品があればそれを最優先**
  - 見つからなければ下のMOSFET＋ダイオードで自作する

### パススルーを自作する場合の部品

- [ ] **PチャネルMOSFET**（ロジックレベル、2A以上） … 2〜3個
- [ ] **ショットキーダイオード**（1A程度） … 2〜3個

TP4056系の安い充電基板は、負荷と電池が並列に繋がるためパススルーにならない。
MOSFETとダイオードを足すと解決できる（定番回路）。合わせて¥100程度。

## 帰ってからの順番

1. スピーカーを繋ぐ（**音量を35%より下げてから**。耳から離して最初の1回）
2. USB電流チェッカーで4場面を測る（起動時・待機・会話中・音量最大）
3. 数字から電池の持ち時間を計算し、容量が足りているか判断
4. テスターで ReSpeaker の電源経路を追う（3.3V直結が可能なら昇圧が不要になる）
5. 静かなタイミングがあれば VAD計測（低域比の検証、10分）
