# A. 現フェーズ — 最小単位で動かす

🔒 **ここが終わると「ブレッドボードに見えない1台が、電池で立ち上がって会話して、
爆音が出ない」状態になる。** 筐体もサービスも入っていない。

## A-1. 基板を組む — [POWER.md](POWER.md) 4章 / [relay_board.html](../hardware/relay_board.html)

🔒 **図（引き直し）は済んでいる。残っているのは組むことと、その前提3つ。**

✅ **2026-08-17、ユーザーが穴割りを全面的に引き直して 赤0・黄0 になった。**
OLED を行E へ、AS5600 を列25 へ移し、I2C と GND の幹線をそれに合わせて引き直してある。
**交差もゼロ**なので、板の上の被覆線は最後まで直角だけで通る。
⚠ これまで「黄は構造的に避けられない交差」と書いていたが、**避けられた。**

🔴 **ただし穴割りは凍結していない（2026-08-15・ユーザー）。**
「ハブ基板はまだ組み立てていないので何でもできる。どうせ筐体設計したらこうなるだろうと思っていた」。
→ **穴割りは筐体に従わせてよい。** 箱詰めスタディ（[DIMENSIONS.md](DIMENSIONS.md) 0.5）で
**ハーネスの通り道が体積の31%を食う**ことが分かっており、その大半は
**行A（`A14`〜`A20`・ReSpeaker行きの7本）をどこに置くか**で決まる。

✅ **会話ボタンは、板の直挿しと筐体側の口の両方を持つ（2026-08-17・ユーザー決定）。**
板に直挿しのボタンは**維持する。** そのうえで、筐体の天板にも同じスイッチを付けるので、
GND と D2 の**2ピンの口を板の右端に足した。** 2つは並列なので、どちらを押しても
D2 が GND に落ちる。⚠ **穴の番号は [relay_board.html](../hardware/relay_board.html) が唯一の正**
なので、ここには書かない。

🔴 **「直挿しは廃止・復活はもう無い」と書いてあったのは誤りで、2026-08-17 にユーザーが
明確に否定した**（「だめです。維持」）。**これはユーザーの決定ではなく AI が勝手に
書いたものだった。** 元は「箱詰めスタディで OLED が塞いでいてパドルを外から下ろす経路が
無い」という観察だが、**観察から廃止までを勝手に進めたのが間違い。**
⚠ **この種の書き換えを二度としないこと。** ユーザーが言っていない決定に ✅ や 🔒 を
付けない。観察は観察のまま ⬜ で置く。

⬜ **同時に見直すもの: 行S の通り道。** `S3`〜`S19` に**4つの口が集中**している。
会話ボタンはここに加えず板の右端へ逃がしたので4つのままだが、
25mm の通り道（[DIMENSIONS.md](DIMENSIONS.md) 1.5）が
行S 側にも要るなら Y がさらに伸びる。**行き先が箱の下段（PowerBoost・INA226）か
パネル（トグル・リード・ボタン）かで要る空間が違う**ので、分けて数えること。

|---|---|---|---|---|
| 🔴 | **板を組む（半田）** | 電気 | ユーザー | 下の3行 |

| 🟡 | 音量の上限 | コード | AI | スピーカーを繋いでの実測 |

🔒 **2026-08-15、つまみは v4 で引き直した。** 抜け止め・軸受け・上下の止め・リード
スイッチ・回転の壁が1つの設計に入っている。⚠ **[knob_top.scad](../hardware/knob_top.scad)
（v3）と、そこから出た knob_top_*.stl は刷らないこと。** v3 には上向きの止めが無く、
フランジ φ21 が AS5600 の柱へ 2.16mm 食い込んでいて、そもそも組めない。

v4 の要点（詳細はファイルのヘッダー）:
- つまみを天板の穴（φ16）へ上から落とし、**半月2枚**を左右から差し込んで M2.5 で留める
- 軸に段を2つ作り、そのあいだの首（3.2mm）に半月（3.0mm）が嵌まる。上下の遊びは
  **つまみ1部品の中の寸法**なので印刷で出る（天板との足し引きではない）
- 持ち手は φ27.4 × 2.5 のへこみに沈む。外へ出るのは 10.0mm
- リード用磁石は持ち手の**裏面**（面が真下）。**磁石の面から接点まで 2.97mm**（5mm まで）
- 回転の壁は 315度。AS5600 の柱は上側を外へ広げて、ツメの通り道を空けてある
- 天板の下に要る深さ 18.2mm、座 44×28mm

干渉は OpenSCAD で当ててある（[_chk4.scad](../hardware/scratch/_chk4.scad)）。つまみ⇔天板、
つまみ⇔半月、ねじ⇔基板は実体ゼロ。ツメの一周ぶんの掃過体も、回転の壁以外には当たらない。
