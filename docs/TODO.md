## 2.5 音量つまみ — [KNOB-ENCODER.md](KNOB-ENCODER.md) / [KNOB-TROUBLE.md](KNOB-TROUBLE.md)

✅ **AS5600 へ移行済み。**

| | 項目 | 種類 | 誰 | 何待ち |
|---|---|---|---|---|
| 🔴 | **リードスイッチが閉じる距離を測る** | 検証 | ユーザー | ✅ **無し。部品は 8/3 から手元**（テスターの導通レンジ＋磁石を近づけるだけ） |
| 🔴 | **つまみに φ6×2mm の磁石ポケットを足して刷り直す**（外周） | 機構 | AI（図）→ユーザー（印刷） | 上の距離 |
| 🔴 | **ホルダ側にリードスイッチの座を足して刷り直す**（2.5×14mm） | 機構 | AI（図）→ユーザー（印刷） | 上の距離 |
| 🟡 | 磁石の距離が回転角で揺れる | 機構 | ユーザー | ✅ **無し。まず `knob` で再確認**（8/5の観測。8/11 にホルダを刷り直したので、直っている可能性がある） |
| 🟡 | 音量の上限 | コード | AI | スピーカーを繋いでの実測 |

🔴 **上の3行は 2026-08-14 に追加した。** リードスイッチは 8/1 に決まっていたのに、
8/5〜8/10 に刷った治具（[knob_jig.scad](../hardware/knob_jig.scad) ／
[as5600_holder.scad](../hardware/as5600_holder.scad)）のどちらにも座が入っていない。
⚠ **順番を守ること。距離を測る前に刷ると、まず確実に2回刷ることになる。**
モデルは [parts.scad](../hardware/parts.scad) に `reed_switch()` と `magnet_reed()` が
実寸であるので、**刷る前に CAD で当てられる。**

⚠ **恒久の制約（作業ではない）**: `D1`(GPIO2) は XMOS のリセット線なので使わない（`pinMode` 禁止）。
⚠ **監視中（再発したら着手）**: XMOS が起動時に1回だけ落ちた（再現1回・2026-08-05）。
