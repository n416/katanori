## 1. 箱

外寸 **86.65 × 74.99 × 52.95mm**、内寸 **84.354 × 72 × 48.454mm**。手のひらに乗る大きさで、
前が画面、上が操作面、後ろが開く蓋、という置き方をします。

- **正面**（フロント板）に OLED の窓と、マイクのヒゲ（貫通スリット）。
- **天面**につまみ・会話ボタン・スピーカーのグリル。🔒 **つまみは OLED から見て右**です。
  使う人（介護の現場・高齢の方）の殆どが右利きで、右手で回すためで、これが設計の最上位の条件です。
- **左の壁**にイヤホンジャックの丸い口。ReSpeaker 自身の USB-C は 🔒 外に出さず、壁の内側の盲ポケットで受けます。
- **右の壁**に XIAO の USB-C の口。
- **後ろ**（ハッチ）に充電の Type-C の口、トグルスイッチ（尻尾つき）、電池の交換用の蓋。

板は 6 枚（床・左の壁・右の壁・天面・フロント・ハッチ）で、落下を前提に厚み **2.0mm** です。

## 2. 中身の積み方

下から順に重なります。組む順もこの順です。

| 段 | 何が入るか |
|---|---|

| 床に立つ | **ReSpeaker Lite**（＋直付けの XIAO）を前の溝に立てる。**OLED** を前に立てる |
| 左の壁ぎわ | **Type-C 基板**（20 × 15 × 1.6）を板の裏で左壁の内面に付けて立てる。`X 1.694〜3.294・Y 57.4〜72.4・Z 0.5〜20.5`。床の受け（底の座・前の当て・前の返し・後ろの控え）に座り、ブリッジの帯の裏の押さえが Z の抜けを止める。**壁と一緒に降ろす** |

| 帯の天板 | **電流計（INA226）**（`X 10.53〜49.37・Y 16.17〜36.27・Z 31.20〜46.50`）と **PowerBoost**（`X 10.97〜47.53・Y 32.77〜66.31・Z 30.88〜44.60`）。どちらも部品面が上。板の浮きは PowerBoost が 0.5、電流計が **1.0**（`INA_LIFT`・ネジの先と電池の隙間を 0.1 → 0.6 にするため）。**傾きは 2 枚で別**です: PowerBoost は 🔒 2026-08-25 の **10°**（後縁を蝶番に前が持ち上がる）、INA226 は 🔒 2026-08-26 の **0°（水平）** |

## 3. 動かせないこと（🔒 ユーザー決定）

- **つまみは OLED から見て右。** 線・口・組み立ての都合は全部この下です。
- **固定は OLED・ReSpeaker・ハブ基板の 3 つ。** 天面につまみ（AS5600）・会話ボタン・スピーカー。他は位置もサイズも自由でした。
- **ハブ基板は X 中央**（`HUB_DX = 0`）。
- **電池はハブの上に平置き**で、タブは後ろ向き。**交換は後ろから**。
- **樹脂にネジは切らない。** 全部が貫通＋ナットです（[DIMENSIONS.md](DIMENSIONS.md) の方針）。
- **スイッチは `part=` 一本**（v3 と同じ）。値の一覧は [case_v4.scad](../hardware/case_v4.scad) 冒頭のコメントが正です。
- **開口はベベル、穴は殻の大きさ**（スカスカにしない）。継ぎ目は 45°。丸みの持ち主はフロント＝天面 ＞ 側面 ＞ 背面 ＞ 底面。
- **刷るのは光造形**（🔒 ELEGOO Mars 3・層 0.05）。薄壁は 0.3mm が形になる実績（[PRINT.md](PRINT.md)）。

## 4. 印刷部品

🔒 2026-08-27 ユーザー「v4 ディレクトリにまとまるのが筋」で、**刷る物の STL は `stl/v4/` の 1 か所に集めます**
（`python hardware/_stl_v4.py` が両方の .scad から焼きます）。卓上テストの天板（`deck`）は
道具なので、この 19 点には入りません。
🔒 2026-08-27 ユーザー「rod はもう完全にいりませんね」で、押し棒（`rod`）は knob_v5.scad から削除しました。

| 部品 | `part=` | 刷る向き |
|---|---|---|
| 床 / 左の壁 / 右の壁 / 天面 / フロント / ハッチ | `p_floor` 〜 `p_hatch` | `print_*` で外面を下・底 Z0 |
| 電池の蓋 / 蓋のロック / 尻尾 | `p_shutter` / `p_lock` / `p_tail` | 同上 |
| ブリッジ | `print_bridge`（`part="bridge"` は見る用の一式のまま） | 皿を伏せる（レール・パッド・ビスの座は全部上を向く）。**皿の裏が平らにプレートへ着く**（接地 2263mm²）。⚠ 2026-08-27 まではここに充電の Type-C の押さえが 0.7 下がっていて皿が浮いていたが、🔒 ユーザー指示で押さえを左の壁へ移した。🔴 **支えの無い天井が 65mm² ある**（下の「⚠ ブリッジの掘り込みの天井」） |
| 前板（電池の返し＋前の脚） | `print_brgfront` | **前面を伏せて寝かせる**（🔒 2026-08-26 ユーザー）。前面（Y 12.9）は **634mm² の 1 枚の平らな面**でそのままベッドに着き、フランジは真上へ立つ壁になるので庇が出ない。高さ 8.0 |
| 留め帯 A / B / C（3 点） | `print_strap_a` / `print_strap_b` / `print_strap_c` | 足とツバを下・座を上（模型のままの向き）。ツバの上面が 45° なので支えが要らない |
| 会話ボタンのキャップ | `print_btn` | 閉じている天面を伏せる（空洞と押し棒が上を向く） |
| 🆕 会話ボタンの留め板 | `print_btnplate` | そのままの向きで、板の裏をベッドへ（厚み 1.5mm の平板・体積 212mm³・接地 142mm²）。🔴 2026-08-29 まで `print_btntest`（試し刷り）の中にしか無く、本番の刷る物に入っていませんでした |

| 🆕 つまみ / つまみの島（2 点） | `knob_v5.scad` の `part="knob"` / `part="wall"` | つまみは天面を伏せる（軸が上・背 21.40）、島はへこみの底を下（背 3.90）。書き出しは `python hardware/_stl_v4.py knob knobwall` で `stl/v4/v4_knob.stl` ／ `v4_knobwall.stl` |

下の 5 行は 2026-08-26 に出口を付けました。それまでは板 9 点しか STL に出せませんでした。
同じ日に、ブリッジから**前板（電池の返し＋前の脚）を切り離して別部品にしました**（🔒 ユーザー）。
ブリッジは皿と脚が直角に付いた L だったので、どちらの面を下にしても片方が宙に浮いていました。
前板は**ビスを使わずに**、下は床の溝、上は皿を貫く抜き＋皿の裏の掘り込み（深さ 1.0）に差した
フランジ（厚み 1.0・奥行き 6.0）で止まります。フランジは掘り込みに丸ごと沈むので皿の裏へは出ません。
**前へ倒れようとするとフランジの背が掘り込みの天井（Z 22.4）に当たり、後ろへ倒れようとすると
首の背が抜きの奥（Y 15.1）に当たります**。どちらも面で受けます（首の背は 23 × 2.0）。
組む順は**前板を先に床の溝へ差してから、ブリッジを真上から降ろす**
（[_brgf_sec.png](../hardware/_brgf_sec.png) ／ 抜いた姿は [_brgf_fit.png](../hardware/_brgf_fit.png)）。

**⚠ ブリッジの掘り込みの天井（2026-08-28・15 度目の机上の通し）**。
その掘り込みは皿の裏のへこみなので、皿を伏せて刷ると**へこみの天井が下を向きます**。
`_stl_preflight.py` はここを **支えの無い天井 65mm²**（刷る向きで Z 1.10・X 19.9〜38.2・Y 15.3〜18.5・1 層）
と読みます。掘り込みは前（首を通す抜きの側）へ開いていて、天井を支える壁は左右と奥の 3 方だけです。
**⚠ 「支柱を立てられない」わけではありません**（2026-08-28・ユーザー指摘で訂正）。
掘り込みはプレートへ向かって開いているので、**柱を立てる空間は空いています**。
`_v4_props.py` が 0 本なのは `keepout_bridge()` が `brgf_cuts()`（この掘り込みそのもの）を
keepout に入れているからで、**こちらが書いたルール**です。
本当の制約は場所ではなく**痕**です。掘り込みの実寸は**公称 1.0 ＋ 逃げ 0.1 ＝ 1.1**（天井は Z 22.5）、
フランジの厚みは 1.0 なので、**差し込みの逃げは 0.1mm**。支柱の痕の実績は **0.3mm**
（`knob_v5.scad` の「痕 0.3 の実績」）で、痕はフランジが滑り込む天井の面に残ります。
⇒ **サポートを入れるなら、先に掘り込みを深くする**（`BRGF_SINK` 一箇所）。
その代わり前板が前へ倒れる余裕が増えます（逃げ 0.1 で約 1°・0.4 なら約 4°）。⬜ ユーザー判断。
上の本文の「深さ 1.0・天井 Z 22.4」は逃げを含まない公称値で、実寸はこちらが正です。

**危険度の見立て**: 天井は膜ではなく**厚み 0.9mm の棚**（皿 2.0 − 掘り込み 1.1）で、
左右と奥の 3 辺で繋がり、自由なのは手前の 1 辺だけです。**一番遠い点でも奥の壁から 6.0mm**。
preflight の「支えから 2.0mm 超」は部品を選ばない一般のしきい値なので、ここは
**このまま刷って前板が入るかを見る**のが安いと考えます。⬜ 刷ってから
（絵: [_brg_pocket_zoom.png](../hardware/_brg_pocket_zoom.png)）。
🔴 [CASE-V4-OPEN.md](CASE-V4-OPEN.md) の T-6 には「支えの無い天井 **なし**・接地 2304mm²」と書いてありますが、
それは 2026-08-27 に押さえを壁へ移した時点の値です。いまの STL は 65mm² / 2263mm² です。

刷る前に「底の Z が 0 か」と「最薄肉」を機械で見ます（[PRINT.md](PRINT.md)）。
留め帯の設計上の最薄はナットの床 **0.35mm** です。

## 5. 締結

ビスは **25 本**、長さは 4 種類（`M2×4` / `M2×6` / `M2×15` / `M3×8`）だけです。
🔴 2026-08-27 まで見出しは **27 本**でしたが、それは表につまみの島の 2 本が抜けていた数え忘れでした（正しくは 29 本）。
🔒 2026-08-28 に **AS5600 の基板の 4 本を廃止**（棒＋E リングへ）したので、いまは **25 本**です。

| ビス | 本数 | どこ |
|---|---|---|
| `M3×8` | 4 | ハブ基板 → 床（頭は床の裏のザグリ・ナットは基板の上） |
| `M2×15` | 3 | 床の裏 → 左右の壁の下の柱（前 2・後ろ右 1。後ろ左は無し） |
| `M2×4` | 6 | 電流計 / PowerBoost → 留め帯の座（**ナットは横から差す捕捉溝**） |
| `M2×6` | 2 | ブリッジ → 壁の棚（左前・右）。上から。**ナットは棚に横から差す** |
| `M2×4` | 1 | ブリッジ → 帯の左端の耳（左**前** `Y 47.7`）。頭の底 24.8 から棚の底 20.8 まで積みがちょうど 4.0 で、**余りが出ない**。🔒 2026-08-26 ユーザー「ネジの長さは留め金の長さで調整したい」。この 1 本だけ棚が帯の前（OLED 側）に立つ ── 後ろだとドライバが天面ボスに当たる（CASE-V4-OPEN の T-1） |
| `M2×6` | 2 | つまみの島 → 天面（上から・**ナットは天面の裏の下向きポケット**） |
| | | 電流計の 2 本は 🔒 2026-08-26 に**板の浮きを 0.5 → 1.0**（`INA_LIFT`）にしました。座が `3.0` になり、天井 0.4 ／ ナット 1.7 ／ 床 0.9 で**掛かりは満（1.6）のまま**、**ネジの先と電池の上面は 0.1 → 0.6** です。ナットは座の**天井**に居て板と一緒に上がるので、**ネジは M2×4 のまま**で足ります（`_seat_probe.scad`） |
| `M2×6` | 2 | OLED → 天面の L（前から・ナットは L の後ろ） |
| `M2×6` | 4 | 天面の四隅（後ろ 2 は壁の柱、前 2 は 天面＋フロントの耳＋耳柱 の 3 枚） |
| `M2×6` | 1 | 電池の蓋のロック |

ほかに、トグルはハッチの外から六角ナット 1 個、電池の蓋の磁石が φ6 × 2.0 を 4 個です。
**E リングが 4 個**あります —— つまみの軸に**呼び6** 1 個、AS5600 の基板を受ける**呼び3** 3 個（🔒 2026-08-28 に基板のねじ止めを廃止。[KNOB-ENCODER.md](KNOB-ENCODER.md)）。

**ナットの向きが 2 種類あります。** 床・天面・耳のボスは上向きのポケットで、落とし込んで箱を傾けなければ残ります。
留め帯の 6 か所とブリッジの棚の 3 か所は**横から差す捕捉溝**で、上下の肉で閉じ込められるのでどう向けても落ちません。

## 6. 線

13 束 39 本です。通り道は 4 本 —— 左の溝（`X 5.4〜13`）・右の溝（`X 53〜80`）・
後ろの縦穴（`Y 62.9〜72`）・帯の上の棚（`Z 31.4〜43`）。

**線には高さの階が 2 つあります。** 低い車線（`Z 19`）はブリッジの皿と帯の**下**を通り、
上の車線は皿や帯の**上**を通ります。これが組む順を決めています（下の §7）。

| 階 | 束 |
|---|---|
| 低い車線（ブリッジより先） | XIAO 7・つまみ 5・BTN2 2・スピーカー IN 2・スピーカー OUT 2 |
| 上の車線（ブリッジより後） | OLED 4・電流計の I2C 4・トグル 2・リード 2・充電 2 |
| 電源系（基板が入ってから） | PWR 3・電池線 2 ＋ 2 |

模型は [_v4_core.scad](../hardware/_v4_core.scad) の `w_*()`（1.5 角の箱・直角のみ）。
接点の世界座標は `W="pts"` が echo で吐きます（手で写さない）。

**たるみの行き場**（2026-08-26 に測った。組み立てマニュアルの「まだ埋まっていない」から移した）。
作る長さは模型の実長 ＋65mm なので、閉じた後に最大 40mm の余りが 4 束ぶん、箱の中へ戻ります。
箱の中の空きは **195,910mm³**（内寸の 2/3）で、1mm の格子で塊に割ると **186,185mm³ が 1 つながり**です
（残り 142 個は合計 1,000mm³ 足らずの隅）。4 束ぶんの余りは 2.2mm の束 × 40mm × 4 ＝ **約 600mm³** なので、
行き場そのものはあります。逃がし先は**後ろの縦穴**（27,865mm³）と**右の溝**（65,944mm³）です。

🔴 **空いていても、たるみを置いてはいけない道が 3 本あります** —— **電池の抜き道**・**蓋の横スライド**・
**ハッチの爪**。ここに線が寄ると、電池の交換で線を噛みます。

## 7. 組み立て

**手順は [assembly_v4.html](../hardware/assembly_v4.html)**（挿絵つきの 12 手順）にあります。作り直しは
`python hardware/_asm_manual_v4.py`、段の中身と軌跡の検査は [_asm_sim_v4.scad](../hardware/_asm_sim_v4.scad) が持ちます。

順番の骨は 2 つの制約です。**ハブの口 10 本はブリッジより先**（皿と帯が上に載って届かなくなる）、
**上の車線はブリッジより後**（先に上げるとブリッジが降りない）。
そこから出た 12 段が —— 床にハブ → ReSpeaker → ハブの口と低い車線 → 左右の壁（**Type-C 基板を抱いて降ろす**）→
ブリッジ → 電池 → 留め帯 → 電流計と PowerBoost → OLED と上の車線と電源系 → 天面の小組 → 天面とフロント → ハッチ、です。

🔴 3 つめの制約が 2026-08-25 に加わりました。**Type-C の充電基板は左の壁と一緒に降ろす**。板の裏を受ける面が
左壁の内面そのものなので壁より先には立てられず、かといって壁の後から真上に落とすと天面の後ろ左のボスが
経路を 75.6mm³ 塞ぐ（`close_tc`）。一緒に降ろす 1 通りだけです。

⚠ この番号は CAD の軌跡検査から起こしたもので、**①〜⑬の原文をユーザーが書いたものではありません**（[CASE-V4-OPEN.md](CASE-V4-OPEN.md)）。
