## 1. 箱

外寸 **86.65 × 74.99 × 52.95mm**、内寸 **84.354 × 72 × 48.454mm**。手のひらに乗る大きさで、
前が画面、上が操作面、後ろが開く蓋、という置き方をします。

- **正面**（フロント板）に OLED の窓と、マイクのヒゲ（貫通スリット）。
- **天面**につまみ・会話ボタン・スピーカーのグリル。🔒 **つまみは OLED から見て右**です。
  使う人（介護の現場・高齢の方）の殆どが右利きで、右手で回すためで、これが設計の最上位の条件です。
- **左の壁**にイヤホンジャックの丸い口。ReSpeaker 自身の USB-C は 🔒 外に出さず、壁の内側の盲ポケットで受けます。
- **右の壁**に XIAO の USB-C の口。
- **後ろ**（ハッチ）に充電の Type-C の口、トグルスイッチ（尻尾つき）、電池の交換用の蓋。

板は 6 枚（床・左の壁・右の壁・天面・フロント・ハッチ）で、落下を前提に厚み **2.0mm** です。

## 2. 中身の積み方

下から順に重なります。組む順もこの順です。

| 段 | 何が入るか |
|---|---|
| 床 | **ハブ基板**（`X 74 × Y 52`）を平置きで M3 ×4 留め。X は箱の中央（`X 6.0〜80.0`）、前縁は `Y 15.9` |
| 床に立つ | **ReSpeaker Lite**（＋直付けの XIAO）を前の溝に立てる。**OLED** を前に立てる。**Type-C 基板**を左の壁ぎわに立てる |
| ハブの上 | **ブリッジ**（左右の壁を渡す平板＋電池の受け皿）。皿は `Z 21.4〜23.4`、壁〜壁の帯は `Y 50.5〜62.9`。前の 1 枚板の脚が床の溝に座る |
| 皿の上 | **電池**（1000mAh・50 × 35 × 6）を平置き。`X 15.5〜50.5・Y 12.9〜62.9・Z 23.4〜29.4`。🔒 タブ（JST）は後ろ＝ハッチ側 |
| 電池を抱く | **留め帯 3 本**（⊓ 断面）。`Y 15.45〜21.45 / 33.2〜42.2 / 52.6〜58.6`。天板に基板の座が乗る |
| 帯の天板 | **電流計（INA226）** と **PowerBoost**。どちらも部品面を上にして **10° 傾け**、後縁を蝶番に前が持ち上がる。板は天板から 0.5 浮く |
| 天面 | つまみ（AS5600 の島）・会話ボタン・スピーカー・リードスイッチが天面にぶら下がって一緒に降りる |

電池は組んだ後も、ハッチの蓋を開けて**後ろへ引き出せます**（工具なしの交換）。

## 3. 動かせないこと（🔒 ユーザー決定）

- **つまみは OLED から見て右。** 線・口・組み立ての都合は全部この下です。
- **固定は OLED・ReSpeaker・ハブ基板の 3 つ。** 天面につまみ（AS5600）・会話ボタン・スピーカー。他は位置もサイズも自由でした。
- **ハブ基板は X 中央**（`HUB_DX = 0`）。
- **電池はハブの上に平置き**で、タブは後ろ向き。**交換は後ろから**。
- **樹脂にネジは切らない。** 全部が貫通＋ナットです（[DIMENSIONS.md](DIMENSIONS.md) の方針）。
- **スイッチは `part=` 一本**（v3 と同じ）。値の一覧は [case_v4.scad](../hardware/case_v4.scad) 冒頭のコメントが正です。
- **開口はベベル、穴は殻の大きさ**（スカスカにしない）。継ぎ目は 45°。丸みの持ち主はフロント＝天面 ＞ 側面 ＞ 背面 ＞ 底面。
- **刷るのは光造形**（🔒 ELEGOO Mars 3・層 0.05）。薄壁は 0.3mm が形になる実績（[PRINT.md](PRINT.md)）。

## 4. 印刷部品

全部で **14 点**です（つまみ一式は [knob_v5.scad](../hardware/knob_v5.scad) が別に持ちます）。

| 部品 | `part=` | 刷る向き |
|---|---|---|
| 床 / 左の壁 / 右の壁 / 天面 / フロント / ハッチ | `p_floor` 〜 `p_hatch` | `print_*` で外面を下・底 Z0 |
| 電池の蓋 / 蓋のロック / 尻尾 | `p_shutter` / `p_lock` / `p_tail` | 同上 |
| ブリッジ | ⬜ **印刷用の出力が無い**（`part="bridge"` は見る用の一式） | ⬜ 未決 |
| 留め帯 A / B / C（3 点） | ⬜ **印刷用の出力が無い** | ⬜ 未決 |
| 会話ボタンのキャップ | ⬜ **印刷用の出力が無い**（v3 の `p_btncap` が移っていない） | ⬜ 未決 |

刷る前に「底の Z が 0 か」と「最薄肉」を機械で見ます（[PRINT.md](PRINT.md)）。
留め帯の設計上の最薄はナットの床 **0.35mm** です。

## 5. 締結

ビスは **24 本**、長さは 4 種類（`M2×4` / `M2×6` / `M2×15` / `M3×8`）だけです。

| ビス | 本数 | どこ |
|---|---|---|
| `M3×8` | 4 | ハブ基板 → 床（頭は床の裏のザグリ・ナットは基板の上） |
| `M2×15` | 3 | 床の裏 → 左右の壁の下の柱（前 2・後ろ右 1。後ろ左は無し） |
| `M2×4` | 6 | 電流計 / PowerBoost → 留め帯の座（**ナットは横から差す捕捉溝**） |
| `M2×6` | 4 | AS5600 の基板 → つまみの島の柱（下から） |
| `M2×6` | 2 | OLED → 天面の L（前から・ナットは L の後ろ） |
| `M2×6` | 4 | 天面の四隅（後ろ 2 は壁の柱、前 2 は 天面＋フロントの耳＋耳柱 の 3 枚） |
| `M2×6` | 1 | 電池の蓋のロック |

ほかに、トグルはハッチの外から六角ナット 1 個、電池の蓋の磁石が φ6 × 2.0 を 4 個です。

**ナットの向きが 2 種類あります。** 床・天面・耳のボスは上向きのポケットで、落とし込んで箱を傾けなければ残ります。
留め帯の 6 か所だけは**横から差す捕捉溝**で、上下の肉で閉じ込められるので帯をどう向けても落ちません。

## 6. 線

13 束 39 本です。通り道は 4 本 —— 左の溝（`X 5.4〜13`）・右の溝（`X 53〜80`）・
後ろの縦穴（`Y 62.9〜72`）・帯の上の棚（`Z 31.4〜43`）。

**線には高さの階が 2 つあります。** 低い車線（`Z 19`）はブリッジの皿と帯の**下**を通り、
上の車線は皿や帯の**上**を通ります。これが組む順を決めています（下の §7）。

| 階 | 束 |
|---|---|
| 低い車線（ブリッジより先） | XIAO 7・つまみ 5・BTN2 2・スピーカー IN 2・スピーカー OUT 2 |
| 上の車線（ブリッジより後） | OLED 4・電流計の I2C 4・トグル 2・リード 2・充電 2 |
| 電源系（基板が入ってから） | PWR 3・電池線 2 ＋ 2 |

模型は [_v4_core.scad](../hardware/_v4_core.scad) の `w_*()`（1.5 角の箱・直角のみ）。
接点の世界座標は `W="pts"` が echo で吐きます（手で写さない）。

## 7. 組み立て

**手順は [assembly_v4.html](../hardware/assembly_v4.html)**（挿絵つきの 12 手順）にあります。作り直しは
`python hardware/_asm_manual_v4.py`、段の中身と軌跡の検査は [_asm_sim_v4.scad](../hardware/_asm_sim_v4.scad) が持ちます。

順番の骨は 2 つの制約です。**ハブの口 10 本はブリッジより先**（皿と帯が上に載って届かなくなる）、
**上の車線はブリッジより後**（先に上げるとブリッジが降りない）。
そこから出た 12 段が —— 床にハブ → ReSpeaker と Type-C → ハブの口と低い車線 → 左右の壁 → ブリッジ →
電池 → 留め帯 → 電流計と PowerBoost → OLED と上の車線と電源系 → 天面の小組 → 天面とフロント → ハッチ、です。

⚠ この番号は CAD の軌跡検査から起こしたもので、**①〜⑬の原文をユーザーが書いたものではありません**（[CASE-V4-OPEN.md](CASE-V4-OPEN.md)）。

## 8. いまの検査（2026-08-25 夜・`--backend=manifold`）

**0 が正**です。`chk_press` だけは 6mm³ が正で、0 になったら ReSpeaker の押さえが板に届いていない印になります。

| 検査 | いまの値 |
|---|---|
| `chk_floor` 〜 `chk_hatch` / `chk_all`（板 ↔ 中身＋他の板） | **0** |
| `chk_press`（押さえが届いている証拠） | **6mm³ が正** |
| `close_lwall` / `close_rwall` / `close_top` / `close_hatch`（板を入れる軌跡） | **0** |
| `close_front` | 0.13（0 厚の膜 2 枚） |
| `close_desk`（ブリッジを降ろす） | 171mm³ ＝ **OLED より先に降ろせ**という制約（順番を守れば 0） |
| 軌跡（`_asm_sim_v4.scad` の `CHK=`）: 壁・OLED・上の車線 | **0** |
| 同 ブリッジ 9.79 / 電池 4.16 / 留め帯 9.78 / 基板 2.98 | どれも **BTN2 の線がタクトの足へ渡る最後の枝**で、タクトはまだ載っていない。枝を外すと 0 |
| `seatchk` / `strappb` / `inachk` | ⚠ **0.37mm³**（電流計の板の縁 ↔ 留め帯 A の座。既知） |
| `seathw`（ネジとナットの現物 ↔ 周り） | **0** |
| `seatbolt` | 1.71（ネジの頭が 10° の板に片当たりする分・設計どおり） |
