## 試した順と、駄目だった理由

| | やったこと | 結果 |
|---|---|---|
| 1 | 歯 1 枚を丸ごと凸メッシュにする | 🔴 インボリュートの歯元が凹なので**凸包が太る**。測ると z28 で **0.1752mm**・z22 で 0.0903mm。設計のバックラッシュの半分 **0.12** を超えるので **t=0 で歯が食い込み**、0.0094 秒で QACC が NaN |
| 2 | 歯を放射方向に 8 枚の帯（台形）へ割る | 🔴 台形は凸なので食い込みは消えた（t=0 の接触 0）。しかし**同じ歯の複数の板が同時に当たって拘束が競合**し、歯 1 枚分（12.86 度）回った所で解けなくなる。`Linesearch objective is not convex` が連発 |
| 3 | **歯を中心線で 2 つに割る** | ✅ **凸包の太り 0.0000**（＝実物の歯形と一致）。geom も 627 → **159**。t=0 の接触 0 |
| 4 | つまみをトルク（motor）で押す | 🔴 慣性が小さく加速しすぎて歯が飛ぶ。数千度回る |
| 5 | つまみを角度（position）で駆動 | 🔴 歯が噛んだ瞬間にアクチュエータが暴れる |
| 6 | **つまみを運動学で直接与える**（毎ステップ qpos/qvel を書く） | ✅ つまみは狙いどおり（32→64→96→128→160 度）。🔴 **中継と読み取りが付いてこない**。0.13 秒で DOF 1 が NaN |

## ⭐ 切り分けの結果 ── 原因は接触の解け方

**接触を切って同じ入力を与えると、つまみは最後まで安定して回る**（160 度の指示に対し 131.72 度・暴れなし）。
接触を入れると **0.201 秒**（つまみ 16 度 ＝ 歯 1 枚分をわずかに超えた所）で壊れる。
⇒ **駆動でも単位でも慣性でもなく、歯どうしの接触である。**

## 使った設定（最後の版）

    timestep 0.0002 ／ gravity 0 ／ integrator implicitfast ／ cone elliptic
    iterations 150 ／ ls_iterations 50 ／ tolerance 1e-10 ／ multiccd enable
    歯: condim 1（摩擦なし）／ solref "0.004 1" ／ solimp "0.95 0.995 0.0005"

    慣性は実物の 100 倍（RHO 1.15e-3 → 1.15e-1 kg/cm³）。
      ⚠ 接触の剛性に対して小さすぎて解けないための処置で、**力の絶対値は読めない模型**になる

NaN が出た時刻は 0.0094 / 0.1306 / 0.201 / 0.2797 / 0.3868 / 0.4501 / 1.7372 秒。
**刻みを細かくしても落ちる時刻が動くだけで、落ちること自体は変わらない。**
