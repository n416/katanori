**T-2 OLED の右のナットが入らない ── ✅ 2026-08-26 解決**

OLED は上辺の 2 か所を、天板から下りる L 字（`X 10.0` と `X 76.1`・`Z 46.1`）にビス留めします。ナットは
L の裏のポケットに入れるので、L の裏の面（`Y 6.6`）より奥に空きが要ります。左は全開、**右は 1.3mm** しか
無く、ナットの厚み 1.6 が入りませんでした。

- 🔴 **塞いでいる物を 1 度取り違えました。**初版は「天面のつまみの島」と書きましたが、島は `Y 22.3` より
  奥にしか無く、ここには居ません。部品ごとに撃ち直して**スピーカーの右前の丸み**だと分かりました
  （天板だけ 8.0 ／ つまみだけ 8.0 ／ **スピーカーだけ 1.3**）。全部入りの STL で 1 か所測っただけで
  犯人を名指ししたのが誤りの原因です。絵は [_t2_blocker.png](../hardware/_t2_blocker.png)。
- 🔒 直し方はユーザーの指示です。「スピーカーを少しだけ**内側**に移動すればいいのでは」「つまみも一緒に」
  「両方を +4 移動させてください」── **つまみとスピーカーを内側（−X・右壁から離す向き）へ 4**。
  この 4mm は T-2 と別に、**上から見たときのつまみの位置のバランス**（UI）が目的でもあります。
- 動かしたことで座の柱が INA226 と PowerBoost の板に乗ったため、🔒 ユーザー「バッテリー自体のってる
  ブリッジの帯ごと左に 4mm 移動」で **`BAT_DX` を +1 → −3**（電池・皿・脚・帯・座・両基板が一緒に動く）。
- 帯ごと動かすと INA226 の INPUT/OUT の L 字が左の壁に当たるため、🔒 ユーザー「INA の傾斜を無くして、
  左壁側のピンヘッダを垂直にしたらどうだろう」で **INA226 だけ水平（`INA_THETA = 0`）＋電源の口を直立て
  （`pwr_ra = false`）**。L 字は板の縁の外へ 11.8mm 伸びていたので、直立てにすると板の左端が
  `5.30 → 14.53` になり、壁まで 12.8mm 空きます。
- 併せて直したもの: ReSpeaker の押さえの腕 `54.7 → 52.4`（左へ寄せる案は OLED の線の帯に 20.5mm³ 入る）、
  欠き ④ の右の縁を元の絶対位置 56.25 に残す、**会話ボタンの受けの上の角に幅 5 の縦の溝**
  （INA の一番手前のピンが受けの真下に来て、口の頭 46.0 と受けの底 47.1 の間が 1.1 しか無く線 1.5 が通らない）、
  線 8 束の引き直し（OLED・BTN2・PHIN・I2C・電源 3 系統・つまみ・スピーカー OUT・リード）。
- 結果: **右の空きは 1.3 → 15.7mm**。工具と手の道は 33 本とも通り、`chk_all` `chk_wire` `chk_wire_w`
