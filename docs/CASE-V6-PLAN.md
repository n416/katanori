## 6. つまみと歯車 — 🔒 3 枚で確定（2026-09-13）

つまみの軸は正面の面から後ろへ 19.7（`knob_v5` の `Z_PCB_BOT`）で、その先に AS5600 が来る。
ReSpeaker が幅いっぱい（X 2〜36.007）で寝ているので、**軸を真っ直ぐ降ろすと板を貫く。**

🔒 ユーザー案「つまみをギアで動かして稼働部と読み取り部を遠ざける」で解く。
🔒 **2026-09-13 ユーザー決定: 歯車 3 枚**（2 枚だと磁石の軸が電池に 0.8 × 4.0 食い込んでいた）。
これで **幅 48・板 44 × 81.2 が確定**し、幅 50 の案は消えた。

| | 芯（箱） | 歯数 | ピッチ円 | 歯先円 |
|---|---|---|---|---|
| つまみ | X 24・Y 30.04 | 28 | 14.0 | 15.0 |
| 中継 | X 33.00・Y 21.37 | 22 | 11.0 | 12.0 |
| 読み取り | **X 38.2・Y 10**（板 X 36.2・Y 7） | 28 | 14.0 | 15.0 |

- **1:1 でなければならない。**AS5600 は 1 回転 0〜4095 の絶対角なので、増速すると 1 回転を超えて巻き戻る。
  **3 枚なら両端の歯数を同じにするだけでよく、中継の歯数は比に効かない。**
- 中継の芯は両端から等距離なので、両端を結ぶ線の中点から垂線を 2.332 立てた所に来る。
  この 3 つの数はモジュールと歯数から計算していて、**.scad に直書きしていない**（歯数を変えれば追従する）
- ⚠ **3 枚は 2 枚と回る向きが逆**（つまみと同じ向きに回る）。符号はソフト側（`knobzero`）で吸収する
- 歯先と内壁の逃げは **右 0.3・下 0.5**。歯車の平面は **19.05〜20.85**
### 🔴 帯の在庫は 0.45 しかない（2026-09-13 調停役の裁定 #1）

帯 2.15（ReSpeaker のマイク面 18.85 〜 前の壁の内面 21.0）に中継の歯車（鍔から鍔 **1.700**）を
入れると、**余りは 0.450**。つまみの軸方向の遊び 0.25 と止めピンの掛かり 0.85 はこの中から出る。

そしてこの 0.45 を食うのは公差ではなく、**前の壁の内面の「育ち」**である（片側にだけ出る系統誤差・
接地面積で決まる。`PRINT.md`: LCD 比 9〜11% で +0、26〜27% で +0.2、40〜45% で +0.8〜0.9、50% で +1.2）。

| 前の殻だけ | 3,142mm² | 24.4% | +0.2 | ✅ 通る（余り 0.25・遊び 0.05） |
| 背面の蓋だけ | 4,226mm² | 32.9% | — | — |

## 7.6 リードスイッチ（2026-09-13・**まだ置いていない**）

🔒 **役はスライドスイッチと分かれている。**リードは「つまみを回し切ると切れる」、
スライドは「つまみがどこにあっても・ファームがハングしても落とせる」非常用で、
`EN` ⇔ `GND` に**リード・スライド・0.1µF の 3 つが並列**に入る（`POWER.md` 2 章）。
リードなのは「**電源が無くても効く部品**でなければならない」から。

| | 値 | 出どころ |
|---|---|---|
| OFF の壁 | 🔒 **−14 度**（島は 0 度が芯で ±14・可動域 320.1） | `KNOB-ENCODER.md` 268〜272 と `main.cpp:4125`「**右へ回して**」。正面では時計回り ＝ 角度が減る向き |
| リードの芯（殻の中・固定） | 🔒 **−4 度**（OFF から島側へ 10 度 ＝ v5 の `STOP_OFF_ANG`） | リードが開くのは OFF ＋ 5 度。島の中なので止めピンと当たらない |
| 半径 | ⬜ 磁石が決まってから | |
| ファーム | `KATANORI_KNOB_OFF_DEG` **15 → 25**（＝ 15 ＋ 遊び 9.12） | 筐体側の仕事ではない |

⭐ **回転の向きは v5 と同じ。**歯車 **3 枚は 2 枚と違って入力と同じ向きに回る**ので、
つまみと AS5600 の向きは v5（直結）から変わらない。⇒ **`knobzero` の符号は反転しない。**

### 🔴 皿は磁石の運び手として厳しい

皿の裏で空いているのは軸穴 φ12.85 と止めの溝 r8.5〜10.7 を除いた 2 つの輪だが、
**幅だけ渡すと入る前提で設計が進む。厚みが一定ではない**（上面の窪み `KN_SINK` 0.8 が裏の肉を食う）。

| 半径 | 皿の残り厚み |
|---|---|
| 10.700〜11.250 | **1.700**（窪みの底の真下） |
| 12.000 | 1.967 |
| **12.656** | **2.200** |
| 13.500〜14.250 | 2.500 |

⇒ **厚み 2.2 以上が取れるのは r 12.656〜14.250 の幅 1.594 だけ。**
🔴 **φ4 × 2（手持ち）も φ3 も入らない。**内側の輪は r 6.425〜8.500（幅 2.075・厚み 1.700）。

⚠ **距離**: 皿の裏 23.05 → 殻の内面 21.0 で **2.05**。ただし**止めの溝の底（22.0）だけは 1.00**。
リードは距離で効きが決まるので、この差は効きうる。

⚠ **v5 の 🔒「磁石の軸は接線方向」は持ち越さない。**あの実測（「面をリードに正対させると 2 箇所で鳴る」・
