# ねじを長さで仕分ける道具の一覧（2026-09-07・第 1 版）

問い: 「M2 のねじが長さ違いでゴッチャ。ナットとワッシャーも混ざっている。揺らしたらいい感じで仕分けられる治具は無いか」（2026-09-07・ユーザー）。

手元の物: M2 なべ小ねじ（📄 頭 φ3.8 × 1.4）。記録にある長さは 4・6・8・15（他の長さも混ざっている前提）。M2 ナット（📄 二面幅 4.0・厚 1.6）。M2 ワッシャー（📄 外径 4.3〜5.0・厚 0.3）。

この版は 2026-09-07 に Web で集めた。Printables と Cults3D はボット検証で本文が読めず、検索結果の要約だけで書いた行は「本文未読」と付けてある。
可否や順位は付けていない。M2 で使うときに効く数字だけ、各行の右に置いた。

## 原理は 5 つ

長さで分ける道具は、①1 本ずつ当てて目盛りを読む（ゲージ）、②転がして、長さより広いスリットに落とす、③頭で吊るして流し、
軸の先が抜ける所で落とす、④穴に立てて並べ、頭の高さで見る、のどれか。⑤径だけで分けるふるいは長さを分けないが、ナット・ワッシャーを
ねじから外すのに使われている。⑥ナット・ワッシャー専用の物は別に並べた。
