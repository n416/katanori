## 4. いま調停が要る所

### 🔴 A. 機構が筐体の顔を削りにきている（未反映）

機構側の要求 5 件のうち、薄さ・見た目に効くのは 2 つです。

| | 機構の言い分 | デザインの言い分 |
|---|---|---|
| 軸穴 φ9.0 → **φ12.85** | 皿の抜き φ11 に届く筒が要る。いまは皿と歯車を繋ぐ実体が 0mm³ | 皿 r14.25 の下に隠れるので**見た目には出ない**。反対の理由は弱い |
| 前の面に **深さ 1.0 の溝**（r8.6〜10.6・島 28 度） | 回り止め。無いと 360 度回って 0%↔100% が飛ぶ | **残り肉が 1.0 になる。**大きい平面は板が厚く出る（`docs/PRINT.md`）・沈みが顔に出る恐れ |

ほかに 歯車の平面を 19.05〜20.85（幅 1.8）→ 19.40〜20.80（幅 1.4）、中継の軸 φ3.0 × 1.85、皿の裏 23.30 → 23.05。

### 🔴 B. 機構が板の面積を取りにきている（回路へ未伝達）

1. 立入禁止を 6×6 の角 → 板 (36.2, 7) を芯とする **φ10.2 の円・板の面から 11.3**
2. ブラケットの座: 板 X 35.4〜43.7・Y 0〜6.7 に背 1.5 超の部品を置かない。**右下の M2 で共締め**
3. AS5600 の足跡は**リード込み 4.9 × 6.2**（いまの 4.9 × 3.9 は胴だけ）

板は 44 × 81.2（切り欠き後 3,491mm²）に 7 つの口と電源回路を全部載せた状態で、余白がありません。

### 🔴 C. つまみが抜ける（機構側で作業中）

いまの抜け止めは**圧入だけ**です。ユーザー「スポスポ抜けるじゃん。キミらの機構っていつもそう」。
ねじ／形での確実な保持が要りますが、それは厚みか顔のどちらかを食います。**どちらを食わせるかが調停です。**

## 1. 🔴 A-1 軸穴 φ9.0 → φ12.85 … **通す**

デザイン側の反対理由は元から弱かったが、数で閉じておく。

| | |
|---|---|

## 2. 🔴 A-2 前の面に深さ 1.0 の溝 … **通す。ただしデザイン側の反対理由は向きが逆だった**

デザインの言い分は「残り肉が 1.0 になる・大きい平面は板が厚く出る・沈みが顔に出る」。
**この機では逆である。**

1. **育つのは内面**（`docs/PRINT.md`「育つのは内面なので、天板は同じ +0.9 で六角ナットの
   ポケットと裾を飲んでいる」）。溝はプレート側＝顔の側に開くので、**残り肉は 1.0 のまま、
   あるいは育った分だけ厚くなる。薄くなる向きには動かない。**
2. 「大きい平面が厚く出る」のは接地面積の話で、溝は**平面を 111mm² 減らす**（増やさない）。
   前の殻の初層は溝込みで 3,142mm²（実測 ↓3 章）。

代わりに、機構が書いていない条件が 2 つ付く。**どちらも `hardware/parts/fit.scad` に既にある規則である。**

| | 何 | 出どころ |
|---|---|---|
| ① | 溝の幅は設計 2.2 のまま、**印刷モデルだけ +0.4**（`FIT_BURN`）。手で広げない | fit.scad `fit_hole_down` |
| ② | 溝の底から内面へ **φ1.5 の抜き穴**。無いと吸盤になり「径をいくら広げても入らない」 | fit.scad の ⚠ ・2026-09-10 の小帯 C |

⚠ ②の抜き穴は r9.6 に開くので、**中継の鍔 φ10（芯まで 12.5）を避ける角度**に置くこと。
⚠ 皿は**表をプレート側にして刷る**。止めピンは「印刷の遠い端に立てる」側でなければ太る（fit.scad）。
　これは皿の見える面をプレート側にする向きと一致するので、払う物は無い。

## 3. ⭐ 3 件の残り（軸 φ3.0 × 1.85・皿の裏 23.05・歯幅 1.4）… **通す。ただし帯の残りは 0.45 しかない**

**ここが今日の本題である。**歯車の帯 2.15 に対して、

| | 値 |
|---|---|
| 中継の高さ（鍔から鍔・STL の実測） | **1.700** |
| 帯 21.0 − 18.85 | **2.150** |
| ⇒ **中継が使い切るまでの余り** | **0.450** |
| つまみの軸方向の遊び | 0.25（これを超えると**皿が顔から浮く**） |
| 止めピンの掛かり | 0.85（これを超えると**回り止めが外れて 0%↔100% が飛ぶ**） |

そして、この 0.45 を食う物が 1 つある。**前の壁の内面の「育ち」である。**

🔴 **この機の内面の育ちは公差ではない。片側にしか出ない系統誤差で、接地面積で決まる。**
`docs/PRINT.md` の v4 実測: LCD 比 9〜11% で +0、**26〜27% で +0.2**、40〜45% で +0.8〜0.9、50% で +1.2。

初層の断面を数えた（`--backend=manifold`・**対照は実体の無い z 30 を切って 空**）。

| | 初層 | LCD 比 | 見込みの育ち |
|---|---|---|---|
| 前の殻だけ | **3,142mm²** | **24.4%** | +0.2（v4 の 26〜27% の帯のすぐ下） |
| 背面の蓋だけ | **4,226mm²** | **32.9%** | 30% の線を越える |
| 🔴 **2 枚を同じプレートに載せる** | 7,368mm² | **57.3%** | **+0.8〜1.2**（v4 の実例「大＋小 ＝ 60%」と同じ所） |

⇒ **判定**

| 育ち | 帯 | 中継 1.70 | つまみ | 判定 |
|---|---|---|---|---|
| 0 | 2.15 | 余り 0.45 | 遊び 0.25 | ✅ |
| **+0.2**（前の殻を単独で刷る） | 1.95 | 余り **0.25** | 遊び **0.05** | ✅ 通る。**余りは半分になる** |
| +0.45 | 1.70 | **0** | 皿が 0.20 浮く | 限界 |
| **+0.8〜1.2**（2 枚一緒に刷る） | 1.35〜0.95 | 🔴 **入らない** | 🔴 皿が 0.55〜0.95 浮き、掛かり 0.85 が消える | **組めない** |

⚠ 静的な交差でも出る: 内面を 0.20 下げた殻 × 歯車 3 枚 ＝ **10.52mm³**（0.80 で 113.97・1.20 で 207.83。
育ち 0.001 なら **空** ＝ この検査は空振りしていない）。実物では遊びが先に食われるので潰れはしないが、
**食われる順番がそのまま上の表である。**

1. **歯幅 1.4・帯 19.40〜20.80 を認める。**これ以上細くしても、余り 0.45 は中継の 1.70 で決まっていて増えない
2. 🔴 **前の殻と背面の蓋を同じプレートに載せない。**刷るのはユーザーだが、これは

3. 🔴 **0.45 は帯の在庫である。**誰かが中継の鍔を厚くする・歯幅を戻す・壁を厚くするとき、

⚠ 明記した仮定: 前の殻は**顔を下にして刷る**（顔がこの機で一番正確な面なので、そう刷るはず）。
傾けてサポートで浮かせるなら育ちはほぼ 0 になり、上の表は全部楽になる。**顔の面と帯の 0.45 は同じ数を取り合っている。**

# 裁定 #2 — つまみは「抜ける」前に「回っていない」（2026-09-13・調停役）

機構担当から C（抜け止め）と D（遊び 8.07 度）が返ってきた。**D は認める。C は 接着（④）を採る。**
ただし C の理由は機構が書いたものと違う。

## 1. ✅ D 遊び 8.07 度のまま … **認める。調停は不要**

`firmware/esp32/src/main.cpp` 906 行を自分で読んだ。`abs(pct - knobPercent) >= 2` の
デッドバンドは実在し、両端（0/100）だけ `endstop` で素通りする作りも書いてあるとおりだった。
可動域 310 度で 2% ＝ **6.2 度**。最悪 8.07・RSS 4.70 はこの中に埋まる。
**ばね腕を足しても差はソフトが捨てる。**筐体にも板にも要求は出ない。

## 2. 🔴 C 見つけたこと — **いまのつまみは、抜ける前に回っていない**

機構は「皿の穴 φ8.70 ↔ ハブの柱 φ8.60 で締め代ゼロ」を軸方向の話として報告している。
**同じ隙間は回転方向にも空いている。**

`_v6_gear.scad` の `knob_dish()` が開ける穴は `cylinder(d = KN_PEG + SLIP, ...)` ＝ **真円**である。
一方 `knob_hub()` の柱は φ8.60 を `KN_FLAT = 6.60` の二面幅で削った形。
**φ8.60 の円の部分集合は、どの角度でも φ8.70 の真円に収まる。**⇒ 二面幅には相手がいない。

測った（`--backend=manifold`）:

| | |
|---|---|
| いまの皿を **5 度** 回してハブに当てる | **0.0000mm³** |
| いまの皿を **20 度** 回してハブに当てる | **0.0000mm³** |
| 対照: 穴に二面幅を入れた皿 0 度 / 5 度 / 20 度 | 0.0756 / 0.7998 / **4.1831mm³**（反応） |

⇒ **つまみを回しても歯車は動かない。**`chk_dish_hub = 0.0000` は「締め代ゼロ」ではなく
「**継ぎ手が無い**」と読むのが正しい。

⭐ これで C の選択の形が変わる。**直しは抜け止めと回り止めの両方を同時に供給しなければならない。**

## 3. 🔒 決定 — ④ 接着。ただし「接着」ではなく「厚みの中の肩」を作る

### ② バヨネットを却下する理由（面積でも顔でもない）

**つまみに付けるバヨネットは、回すたびに緩む向きに力を受ける。**可動域 310 度の両端は
機構の壁で、ユーザーは必ずそこへ突き当てて止める（メニューは 0／100 へ振り切って使う）。
突き当てた先のトルクは、半分の回転方向で**外す向き**に入る。掴んで回す部品には向かない。

⚠ 機構が挙げた却下理由（「回り止めの二面幅と両立しない」）は**成り立たない。**
両立させる相手の二面幅が、そもそも効いていないからである（2 章）。

### ④ を採る。そして ④ は接着強度の話ではない

皿の穴の上には**呼び込みの円錐**が既に引いてある（z 22.59〜23.05・**φ8.70 → φ11.00**・容積 34mm³）。

🔴 **ここを満たすと、硬化した栓は皿自身の φ8.70 の穴を通れなくなる。**
皿を 0.1 持ち上げた所で栓は φ9.21 になり、穴 8.70 に噛む。⇒ **リベットの頭である。**
`docs/PCB-MOUNT-SURVEY.md` の分類でいえば、**④ の道具で ② 「厚みの中に肩」を作っている。**
壊れるとすれば φ8.70 の面でのせん断（断面 59.4mm²）で、接着面のせん断 49N とは桁が違う。

そして柱の二面幅の脇に残る**三日月の空所 2 つ**が、同じ栓で埋まって**鍵になる**。
⇒ **1 つの操作で、抜け止めと回り止めの両方が出る。**

### 何で満たすか — 🔒 **同じレジン＋UV。瞬間接着剤ではない**

| | |
|---|---|
| 強さ | `PCB-MOUNT-SURVEY.md` ④「**UV 接合の方が同材で強い**」 |
| 手持ち | レジンと硬化機は**確実にある**（同表）。CA は「手持ちにあれば」＝在庫が不確か |
| ⭐ 決め手 | **硬化のタイミングを自分で選べる。**CA は入れた瞬間に走って固まるので、**回るかどうか確かめる前に決着が付く** |

### 🔒 手順 — 皿の抜き φ11 が注ぎ口と UV の通り道になる

1. 乾組みする（皿を外から落とす → 内からハブを挿す）
2. **回ることを確かめる**
3. 皿の抜き φ11 から未硬化レジンを落として**円錐だけ**満たす
4. 同じ穴から UV を当てて硬化させる

⭐ **ユーザーが 2 度こだわった顔の穴が、そのまま組み立ての口になる。**顔も厚みも 1mm も食わない。
これが「厚みか顔のどちらを食わせるか」への回答である ── **どちらも食わない。**

### 機構への条件 2 つ

| | |
|---|---|
| ① | 皿の穴の底（z 20.79）に**堀**を彫ること。そこがスカートの底＝軸受けの隙間 0.25 に一番近い。走った分はここで止める |

# 裁定 #27 — 柱 `RSP5 − HUB8` の 0.152 は**許す**（2026-09-13）

## 経緯 — 私は聞き方を間違えていた

8 の字の件で、機構担当に「柱 2 本（`HB_Y + 65.25`）の数字を出してくれ」と頼んだ。
**彼は聞かれた組に答えたうえで、柱 10 本を総当たりして、私が知らない組を出してきた。**

| 組 | 芯間 | 柱の肉 | ザグリ φ4 | 通し穴 | 頭 φ3.8 | ナット 4.0 |
|---|---|---|---|---|---|---|
| `OLED2 − HUB8` / `OLED3 − HUB9` | 6.553 | +1.053 | +2.553 | +4.153 | +2.753 | +2.553 |
| 🔴 **`RSP5 − HUB8`** | **5.152** | **+0.152** | +1.152 | — | +1.352 | +1.152 |

✅ **8 の字は解けている**（実体の交差 0・ねじもナットも通る）。
🔴 しかし `RSP5`（箱 4.657, 63.167）と `HUB8`（箱 5.5, 68.25）は**肉どうし 0.152 しか離れていない**。
当たってはいないが、`PRINT.md` §2 の薄壁の下限 **0.3 の半分**。⇒ **根元がくっついて出る。**

## 🔒 裁定：直さない

| | |
|---|---|
| 1 | ⭐ **直す方が戻せない。**`HUB8` を 0.15 動かす＝**板の穴が動く＝基板の作り直し**。殻は刷り直せば済む。**戻せない側を、戻せる側の都合で動かさない** |
| 2 | **Z の重なりは 2.0〜3.0 の 1.0mm だけ**（`HUB8` は板の高さ 3.0 で終わり、`RSP5` は 17.0 まで）。くっついてもねじの通り道にも板の座にも効かない |
| 3 | その 1.0mm は**育ちに飲まれる公算が高い**（床の内面が上がると柱の根元が埋まる。テスト板で柱が 3 本沈んだのと同じ機序） |

⚠ **3 は根拠ではなく傍証。**v6 の皿の接地面積も刷る向きも未測定。
**「埋まるから大丈夫」ではなく「埋まっても埋まらなくても効かない」が裁定の根拠。**

### 条件 3 つ

1. **殻の側に書く。**⚠ 書かないと、次に見た人が「当たっている」と思って直しに行く
2. ⚠ **`RSP5` か `HUB8` の Z を動かしたら裁定は無効。**重なりが 1.0mm を超えたら裁定し直す。
   回路担当にも「`HUB8` の穴を別の理由で動かすなら事前に言え」と伝えてある
3. **刷ったら根元がどう出たかを、育ちの表と一緒に記録する**

## 🔒 常設の検査は**殻の持ち主**（デザイン）に置く

機構担当の `_v6_gear_chk.py` に入れると機構と関係ない物が混ざる。彼の申告どおり。

🔒 **4 段を別々に出すこと。1 つにまとめない。**柱の肉／皿ぐり／通し穴／**頭とナット**。
⭐ **柱が離れていても頭が当たる組がある。**「柱の肉が空」だけ見る検査はそれを見逃す。
今回 5 つの隔たりが別々に出たから、0.152 を「**当たってはいないが刷れない**」と分けられた。

## ⭐ ここから別件に火が付いた — 線の道に Z の下限が要る

床の内面が **+0.8〜0.9** 上がるなら、**床すれすれの物は飲まれる。**
`PRINT.md` に「板の下側 1.2mm にある通路は育ちに埋まる可能性がある」と既に書いてある。
**線の道はまさにその通路。**⇒ 裁定 #26（線の空きは ①口の高さ ②曲げ ③束の断面）に **④育ちの分だけ浮かせる** を足した。

⚠ **私は ④ を落としていた。**機構担当が「柱どうしは私の検査では取れない」と申告した事から出た。
**自分の担当外だと申告する事が、別の穴を開ける。**
