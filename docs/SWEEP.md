# 入れる道の当たり検査と動画 — コマンド集

なぜこの形かは [COLLISION-SURVEY.md](COLLISION-SURVEY.md)。ここは**回し方だけ**。

```
case_v6_1.scad          形と道（PATH_*）の出どころ。ここは触らずに使う
  └ tools/_sweep_v61.scad   呼び出し口（動かす物・相手・1 姿勢の交わり・道の一覧）
       ├ tools/sweep_chk.py      距離で道を走り、当たりを出す   → _tmp_sweep/<key>.json
       │    └ sweep_accept.json    了承済みの当たりの台帳
       └ tools/sweep_movie.py    動画を焼く                     → _tmp_sweep/<key>.mp4
            └ tools/_sweep_blender.py   Blender の中で動く側
```

道は**材料で違う**（`--mat` で切り替える）。

| 材料 | 道 |
|---|---|
| `nylon` | `hub` `rsp` `oled` `bat` `lid` |
| `resin` | `bat` `hub` `rsp` `lwall` `rwall` `top` `front` `hatch`（組む順）。**`oled` は無い** —— OLED はフロントに付いて `front` で入る |

蓋（`lid`）は**たわむ部品**。天板と左の板は 1 つの部品で、左の板が付け根から先へ向かって曲がる
（片持ち梁・付け根 0・口 1.5・下端 3.56）。道の点の **7 つ目がたわみ量**で、これが変わると形が変わる。
形は `flap_bent(d)` が作り、道具はたわみ量ごとに形を作り直して使い分ける。

## 1. 検査

材料の道を全部回す。**新しい当たりがあれば終了コード 1。**

```bash
python hardware/tools/sweep_chk.py --mat resin      # レジン 9 本（2 分半ほど）
python hardware/tools/sweep_chk.py --mat nylon      # ナイロン 5 本（48 秒ほど）
```

`--mat` を書かないと `nylon`。1 本だけ回すなら道の名前を足す。

```bash
python hardware/tools/sweep_chk.py --mat resin lwall
```

出る物は `hardware/_tmp_sweep/resin/` と `hardware/_tmp_sweep/nylon/` に分かれる。
台帳（`hardware/sweep_accept.json`）の各件も `mat` を持っていて、材料が違う件は突き合わせない。

読み方:

- `済` … `hardware/sweep_accept.json` の台帳に載っている当たり（前に見て了承した物）
- `新` … 台帳に無い当たり。**見て判断する物はこれだけ**
- `めり込み無し` … 触れているのは同一平面の皮だけ（板が柱の頭に載る面など）
- `最小隙間 0.000` は「当たっている」ではなく「**触れている**」。皮かどうかは厚みで分ける

## 2. 動画

5 場面とも焼く（1 つ 1〜2 分）。

```bash
python hardware/tools/sweep_movie.py
```

1 つだけ（蓋は `lid`）。

```bash
python hardware/tools/sweep_movie.py lid
```

**覗き見**（3 枚だけ焼く・十数秒）。頭 / 座った所 / 交わりだけ、の 3 枚が出る。
⚠ **焼いたら必ずこれで「物が動いているか」を目で見ること**（動かない絵の上で色と数字だけが変わる事故を起こした）。

```bash
python hardware/tools/sweep_movie.py bat --peek
```

**コマ**（`hardware/_tmp_sweep/<材料>/<場面>_frames/*.png`）は、動画にできたら消す（1 本で数百 MB）。
残したいときだけ `--keep-frames` を付ける。残っているコマがあると、焼くたびに最後に量が出る。
同じ場面を焼き直すと、その場面の古いコマは先に捨てられる。

```bash
python hardware/tools/sweep_movie.py bat --keep-frames
```

絵の読み方:

| 色 | 意味 |
|---|---|
| 青 | めり込み無し（空いている・面で触れているだけ、の両方） |
| 橙 | **了承済み**のめり込み（台帳にある ＝ 決着済み） |
| 赤 | **新しい**めり込み（判断が要る） |

⚠ 色が持つのは「**判断が要るか**」だけ。触れているだけの所を黄色にしていた頃は、
道の全域で触れている蓋が最初から最後まで黄色になり「入らない」と読めた。
了承済みまで赤くしていた頃は、蓋の最後が真っ赤になって台帳の意味が消えた（🔒 ユーザー 2026-09-18）。
触れていることは焼き込みの文字（`touch`）に残す。
交わりを見せるコマでは:

| | |
|---|---|
| 明るい赤の塊 | その姿勢の**交わりそのもの**（OpenSCAD で厳密に取った形） |
| 赤い針金の枠 | いちばん深い塊の場所（小さい当たりを見つけるため） |
| 消えるのは当たっている物だけ | 場面に物が 2 つあるとき、相手（天板など）は残る |

コマの並びは 3 つ:

1. **入れる**（道のとおり動く）
2. 当たりがあれば、**いちばん深い所で止めて動く物を消し、交わりだけ**を見せる（0.8 秒）
3. **組み上がった姿勢に戻して 2.5 秒止める**（🔒 ユーザー 2026-09-18「組み立て完了の状態で数秒維持してほしい」）

焼き込みの文字は `s`（道のどこか）・`gap`（隙間 mm）・`HIT t=…mm V=…mm3`・`>> assembled`。

## 5. 道を直す・足す

道（通過点）は `case_v6_1.scad` の `PATH_HUB` / `PATH_RSP` / `PATH_OLED` / `PATH_BAT` / `PATH_LID`。
**ここが唯一の出どころ**で、検査も動画もここを読む。
1 点は `[dx, dy, dz, rx, ry, rz, d]`（移動 3 つ ＋ 回し 3 つ・度 ＋ **たわみ量**）。
7 つ目は省ける（省くと 0 ＝ 曲げない）。

道を 1 本足すには 3 か所:

1. `case_v6_1.scad` に `PATH_<名前>` を書く
2. `tools/_sweep_v61.scad` の `sw_mover()` に「動かす物」、`sw_world()` に「そのとき箱に居る物」を足す
3. 同じファイルの `SW_MODE == "pose"` の並びに `["<名前>", PATH_<名前>, 回す中心, 端までの長さ]` を足す

回す道なら**回す中心 `c` と、中心から端までの長さ `r` を必ず渡す**
（`c` の既定は世界の原点なので、傾けると物が遠くへ飛ぶ。`r` は刻みを出すのに要る）。

### たわむ物

🔴 **剛体に割らない。形そのものを作り直す。**
2026-09-18 に蓋を 2 つの剛体（天板・左の板）に割って別々に当てたが、左の板を剛体のまま
1.5 横へずらすので**付け根が 1.5 せん断され**、1 つの部品ではあり得ない形になっていた。
（🔒 ユーザー「天板と左壁はつながっています」「お前はなにをしようとしている」）

いまの形: `flap_bent(d)` が Z を 12 段に切り、段ごとに X のせん断（`multmatrix`）を掛ける。
段の境目で値が一致するので繋がったまま。たわみは片持ち梁の式

```
y(x) = d/2 ・( 3(x/L)^2 − (x/L)^3 )      x は付け根からの距離・L は付け根から口まで 26.50
```

で、口より下は荷重が無いので直線。実測で 付け根 0.016・口 1.602・下端 3.559・**1 つの塊**。

道具側は `DELTA_STEP` 0.1 でたわみ量を刻み、**小さい側へ丸める**（たわみが小さい方が逃げが少なく、
判定として厳しい側）。刻みの上限には形の変化分も足す（`DEFL_RATIO` 2.5 ＝ 下端が d の 2.4 倍動く）。

⚠ **蓋を平行移動させる道は作れない。** 蓋は 4 本の上の柱で位置決めされていて、
X にも Y にも **0.3mm** しか動けない（2026-09-18 実測）。口が要る逃げは 1.25mm なので、
それを出せる場所は左の板 1 枚だけ。これがたわみ部品である理由。

## 6. つまみ

`hardware/tools/sweep_chk.py`

| | 既定 | 何 |
|---|---|---|
| `TOL` | 0.05 | これ以下の隙間は「接触」として扱う（clash tolerance） |
| `SKIN_T` | 0.10 | 厚みがこれ未満なら当たりに数えない（🔒 ユーザー 2026-09-18「0.1mm くらい何でも入るよ」） |
| `EXACT_MOVE` | 0.30 | 接触区間の中で厳密な交わりを取る間隔 mm |
| `EXACT_MAX` | 12 | 1 区間あたりの厳密評価の上限（重くしないため） |
| `MIN_MOVE` | 0.02 | 接触区間で 1 歩に進む距離 mm |
| `DELTA_STEP` | 0.1 | たわみ量の刻み（形を作り直す単位）。小さい側へ丸める |
| `DEFL_RATIO` | 2.5 | d が 1 変わると物のどの点も最大これだけ動く（刻みを出すのに使う） |

⚠ **刻みの定数は無い。** 空いている距離から自動で出す（Conservative Advancement）。
広い所は 1 歩で飛び、狭い所だけ細かくなる。

`hardware/tools/sweep_movie.py`

| | 既定 | 何 |
|---|---|---|
| `MM_PER_FRAME` | 0.5 | 1 コマで物が動く距離 mm |
| `FPS` | 24 | |
| `HOLD_HIT` | 20 | いちばん深い所で止めるコマ数（ここで動く物を消す） |
| `HOLD_END` | 60 | 組み上がった姿勢で止めるコマ数（2.5 秒）。**動画はここで終わる** |

## 8. 困ったとき

| 症状 | 見る所 |
|---|---|
| 動画で物が動かない | `matrix_world` に素の配列を入れると列として読まれる。`mathutils.Matrix()` で包む。まず `--peek` で確かめる |
| 動く物が箱の面の裏に消える | EEVEE の半透明どうしは前後関係が壊れる。半透明は箱だけにする |
| 針金の枠が中身の詰まった箱に見える | Wireframe は物を拡大する前に効く。`scale` で大きくしない（頂点を書く） |
| 箱が画面から出る | `ortho_scale` は横に効く。16:9 では縦が先に切れる（外接箱の 8 隅で合わせている） |
| `<key>.json が無い` | 先に `sweep_chk.py <key>` を回す |
| 検査が遅い | 厳密評価の回数（`EXACT_MAX`）を減らす。距離で走る所は 1 本 2〜5 秒しか掛かっていない |
| 模型を直したのに数が変わらない | 出る物の作り直しが `os.path.exists` で止まっていた（2026-09-18 に `cached()` へ直した）。疑わしいときは `hardware/_tmp_sweep/<mat>/` を消してから回す |
| STL が無いので「入らない」と読んだ | OpenSCAD は中身が空だと STL を書かない。ログの `top level object is empty` で判定する |
| `thick` は大きいのに実物は掠っている | `thick` は主軸方向の箱の長さで、潜っている深さではない。曲がった薄い皮だと 20 倍出る。深さは 体積 ÷（面積 ÷ 2） |
| `ext` の並びが軸と合わない | `ext` は大きい順。x,y,z の順ではない |
| `include` して測ったら模型全部が出てくる | `-D part='"__none__"'` を付ける |
| エラーが見えない | OpenSCAD は ERROR を stderr ではなく `-o x.echo` の中に書く |
| F5 のプレビューで面が割れて見える | 面どうしが同じ平面に乗っている。逃げを足すのではなく形を直す（通しが台の天面ちょうどで終わる・円柱を立てて後から引く） |
| 切り欠きが部品の外へ出ているのに 0 が返る | この検査は食い込みと隔たりしか見ない。縁を割っていないかは絵で見る（ゴム足の座 φ10 が板の縁を割っていた） |
| `git apply` が Permission denied | OpenSCAD がそのファイルを開いている。`-R` が通ってから本体が失敗すると、変更が消えた状態で残る |

## 9. 材料で分ける

🔒 ユーザー 2026-09-15「レジン版とナイロン版はスイッチできるわけで、それに応じてアラートを分けて」。
2026-09-18 に対応した。`--mat` で `-D MAT=` を OpenSCAD へ渡し、出る物も台帳も材料で分ける。

レジンの組む順は 🔒 ユーザー 2026-09-18 による。

> ① 電池を置く ② ハブ基盤を置く ③ ハブ基盤の手前をねじ止めする
> ④ 左右の壁を後ろに嵌め、ねじを仮締めしておく
> ⑤ 左右の壁は当該ねじを支点として、右壁は反時計回り・左壁は時計回りに 45° 前方を開ける
> ⑥ ReSpeaker を組み、その後 OLED のライザーを上から入れる
> ⑦ 壁を閉じる ⑧ 奥のねじを本締め
> ⑨ 天板を降ろす
> ⑩ OLED を付けたフロントを入れ、手前のねじで一緒に固定
> ⑪ ハッチ

⑨⑩ は 2026-09-18 に入れ替えた。前は ⑨ フロント → ⑩ 天板 だったが、その順だと天板が上から入らない。
OLED はフロントに付いたまま ⑩ で入る。ライザーは ⑥ で箱に入れて残す
（ライザーと OLED を一緒に前から入れると ReSpeaker を 472mm³ 削る）。
つまみ（トグル）はどの場面にも置かない。後からいつでも付けられるから。

「そのとき箱になっている板」は `case_v6_1.scad` の `world_box(k)` が 1 か所で持つ（板の格子も一緒に。2026-09-18 夜）。
検査（`world_for_*`）も動画の半透明の箱（`SW_MODE="wshell"`）もこれを読む。
**ここを 2 か所に書くとずれる**（2026-09-18: 動画だけ `shell()` のままで、電池の場面に
壁もフロントもハッチも描いていた）。

### 壁を閉じる道（`PATH_LWALL` / `PATH_RWALL`）

床の板と壁の板は箱の角で 45° に切り合わせてある。その斜めの面は Z −2.0〜0 にあり、
床の板も同じ Z にあるので、壁を回すと交わる。壁を持ち上げると斜めの面は上へ逃げる。
要る持ち上げ量は角度で変わる（下の 2 つは 2026-09-18 の測定。塊のいちばん厚い所 mm）。

**壁 × 床**（左の壁。右は同じ傾向でやや小さい）

| 浮き | 45° | 30° | 20° | 15° | 10° | 5° | 2° |
|---|---|---|---|---|---|---|---|
| 0 | 2.337 | 2.214 | 1.989 | 1.677 | 1.474 | 1.214 | 0.747 |
| 1.0 | 1.404 | 1.143 | 0.919 | 0.655 | 0.451 | 0.233 | 0.095 |
| 1.5 | 1.009 | 0.765 | 0.477 | 0.293 | 0.093 | 0 | 0 |
| 2.0 | 0.454 | 0.403 | 0.108 | 0 | 0 | 0 | 0 |
| 2.5 | 0 | 0 | 0 | 0 | 0 | 0 | 0 |

**壁の口 × ReSpeaker のコネクタ**

| 浮き | 10° | 5° | 3° | 2° | 1° | 0° |
|---|---|---|---|---|---|---|
| 左 0.5 | 0 | 0 | 0 | 0 | 0 | 0 |
| 左 1.0 | 0 | 0 | 0 | 0 | 0.415 | 0.762 |
| 右 1.0 | 0 | 0 | 0 | 0.051 | 0.775 | 1.026 |

上の表は「小さい角でも持ち上げろ」、下の表は「下ろせ」と言っている。
実物では手で徐々に閉じるので、道は**持ち上げを下げる一方**にし、最後は 0 で終わる。

```
PATH_LWALL = [[0,0,2.5,0,0,-45],[0,0,2.5,0,0,-20],[0,0,1.5,0,0,-10],
              [0,0,1.5,0,0,-5],[0,0,1.0,0,0,-2],[0,0,0.0,0,0,0]];
```

2026-09-18 までは末尾に「0° のまま浮き 1.0」の点が残っていて、そこで壁の口がコネクタに乗っていた
（左 0.762・右 1.026）。点を外して 0.130 / 0.226 まで下がり、どちらも台帳の 1 件だけになった。

## 10. ナット／ねじの口の検査（`nutpath_chk.py`）

2026-09-18 に組み直した。入れる道の検査（1 章）は「部品が箱に入るか」を見る。こちらは
**ナットを口へ入れる道**と**ねじの頭・ドライバーが通る柱**が、その作業をする場面で空いているかを見る。0 が正。

```bash
python hardware/tools/nutpath_chk.py --mat resin            # 全部の口（36）・23 秒
python hardware/tools/nutpath_chk.py --mat nylon            # 29 口・21 秒
python hardware/tools/nutpath_chk.py --mat resin dhub2 pt0  # 口を選ぶ
python hardware/tools/nutpath_chk.py --mat resin --all      # 全部の場面に当てた表（どの場面なら空くかを探す）
python hardware/tools/nutpath_chk.py --mat resin --dd 3.8   # 頭と工具の柱の径（既定は座ぐり φ4.4）
```

| 物 | 場所 |
|---|---|
| 口の表・場面・世界 | `hardware/tools/_nutpath_v61.scad`（`PROBES`・`np_scene()`） |
| 箱と先に入っている物 | `case_v6_1.scad` の `world_for_*()`（掃引と同じ出どころ） |
