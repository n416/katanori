JLCPCB の部品区分とコスト — 調査のまとめ

2026-09-12 ／ 対象は自作の電源・ハブ基板（hub_power・表面実装 44 個 28 種類）。数字はすべて JLCPCB の部品検索と料金表から取った実測値で、推定は推定と明記した。

1. 何にお金が掛かるのか — 2 種類に分かれる

基板実装の費用は、枚数に比例する分と発注の回数に比例する分に分かれる。ここを混ぜると、枚数を増やせば安くなるはずのものが安くならない、という読み違いが起きる。

この基板では、発注のたびに必ず $37.34 が乗る（段取り $8.18 ＋ メタルマスク $1.53 ＋ Extended 9 種類 $27.63）。枚数に比例するのは 1 枚あたり約 $10.2 なので、5 枚なら費用の 42% が「枚数と無関係な分」になる。

Basic と Extended の違い

JLCPCB は実装に使える部品を Basic／Promotional Extended／Extended の 3 つに分けている。前の 2 つは追加料金がかからない。Extended は部品の種類ごとに 1 回の発注で $3.07 かかる。これは機械にリールを載せ替える手間の料金なので、同じ発注で 100 枚作っても 1 回である。

⚠ 逆に言うと、小分けに頼むと回数ぶん掛かる。5 枚を 5〜6 回に分けて発注する前提なら、Extended 1 種類の実質は $3.07 ではなく $15〜$18 になる。試作を重ねる案件では、ここが効く。

4. 調べ方 — 0 件を「無い」と読む前に対照を取る

この調査でいちばん危なかったのは、検索で 0 件と出たものを「存在しない」と読んでしまうことだった。JLCPCB の検索は部品の説明文への文字列一致なので、書き方が違えば当たらない。実際、この調査では一度これで誤った結論を出しかけた。手順はこうなる。

  1. 部品表の品番を 1 つずつ引いて区分を読む。品番で引けば区分（Basic / Extended）は正しく出る。ここは疑う必要がない。
  2. Extended の物は、値で検索して Basic の絞り込みをかけ、残り件数を読む。
  3. 🔴 0 件が出たら、必ず対照を取る。Basic が在ると分かっている別の検索で同じ操作をして、絞り込みが効いていることを見る。抵抗なら 185 件、10µH のインダクタなら 2 件が残る。ここを飛ばすと、方法の不具合と事実の区別がつかない。
  4. 残り件数が 1 以上でも、件数だけで決めない。実際に品番を開いて定格と大きさを見る。10µH の Basic 2 件は、開いてみたら 3mA と 15mA の信号用だった。

JLCPCB の Basic 一覧ページ（1,586 点）は検索の引数を受け付けず、カテゴリ一覧も途中で打ち切られるので、一覧を端から数える道は使えなかった。上の 4 手順が現実的な方法になる。

5. 数量と発注回数でどう効くか

試作を重ねる案件では、ロットの切り方が部品選定より効く。この基板で 5 枚ずつ作る場合を並べる。

同じ 30 枚でも、6 回に分ければ $530、1 回にまとめれば $343。差の $187 はすべて段取り・メタルマスク・Extended の掛かり直しである。板代と送料は別で、そちらも回数ぶん掛かる。

設計を詰める段階では回数が増えるのは避けられない。そこで効くのは「1 回あたりの固定費を下げておくこと」で、Extended を 12 → 9 種類に減らした効果は、6 回まわすなら $9.21 ではなく $55 になる。

6. この案件で決めたこと

  • Extended 9 種類のまま行く。残りは回路を変える話になるので、$3.07 のために触らない。
  • ミュートリレーは表面実装に替えた（Y14H-1C-5DS → Omron G6S-2F DC5）。手はんだが消え、足形も KiCad 標準の Omron 純正 land pattern になった。Basic のリレーは存在しないので、$3.07 は避けられない。
  • スルーホールは 11 個（ピンヘッダ 8・JST・PH 2）。自分で付けるか、$3.58 ＋ 41 点 × $0.0164 ＝ $4.25 で頼むかは未決。
  • 板代・送料・面付けの追加料金は未確定。発注画面にファイルを上げるまで出ない。
