| BAT | X 55.5 ／ Y 62 で降りる |

🔒 **開口の X は「口の真上に立つ束」で決まる。** 左の開口を 9.5 にしたのは、BTN2 の口
（X 12.52）と AS5600 の口（15.06）から立ち上がる束が **X 11.26〜16.84 を塞いでいる**から。
13 や 15.5 に置くと、PHIN の南北の車線がその2本の付け根を貫く。

⚠ **測り方。**`WIRE_PICK` は**リストも受ける**ようにした（`-D 'WIRE_PICK=["PWR","INA"]'`）。
2本ぶんの和集合を測り、`体積(A) + 体積(B) − 和集合` で重なりが出る。場所を見るときは
`hardware/scratch/_probe_pair.scad`（2つの STL を `import` して `intersection`）。

**🔒 引き継ぐ人が最初に読むもの**
- 通り道の定義は `wires_v2()` の冒頭（LZ / HZ / F / R と LANE_RZ、通路の X）
- 「上がれない X」と空き地図も同じ場所のコメント
- 向きの基準は **OLED が正面**。「横から見た断面」は X 方向から見た Y-Z 面

**🔧 切り分けの道具**（`hardware/scratch/` に置いてある。どれも `-D 'part="none"'` を付けて呼ぶ）

| ファイル | 何が出るか |
|---|---|
| `_probe_hit.scad` | **線1本 × 部品1つ**の当たり。`-D 'WIRE_PICK="INA"' -D PICK=10 -D 'TGT="parts"'`（`TGT` は `parts`/`lower`/`upper`）。**どの部品が相手かはこれでしか分からない** |
| `_probe_col.scad` | 空き地図。`-D CX=30 -D ZL=46.9 -D ZH=50.2 -D Y0=38 -D Y1=64` で、その X の柱が Y を貫けるか。体積 0 なら通れる |
| `_probe_bb2.scad` | 部品を薄くスライスして本当の形を見る（外形の箱ではなく） |
| `part="wires"` | 線だけ。`-D CUT_AXIS=0 -D CUT_AT=45 -D CUT_TH=2` で薄く切れる（真上や斜めからでは束の並びが読めない） |
| `part="rail"` | 背面のレールと線と部品だけ（ブリッジは半透明） |
| `../hardware/frozen/v1-v4/pb_bridge.scad` | **PowerBoost とブリッジだけ**の単体ファイル。`-D VIEW=2` で当たりだけ出る。⚠ `include <case_v2.scad>` の**後ろ**に `part = "none";` を書くこと。前だと case_v2.scad の 57 行に負けて筐体が丸ごと描かれる |
