## ✅ 電池が取り出せるようにした（2026-08-21）

**それまで取り出せなかった。**左の壁には穴が 1mm³ も開いていなかった（実測: 帯 1700mm³

### 🔴 つまみは 6.8 右へ —— 「動かせない」は誤判断だった

AS5600 の板（23 × 23）の右端は X 53.4 で、電池トンネルの端板（52.4〜54.0）へ 0.6 重なる。

⚠ 天面のへこみの右の余白は 8.0 → **6.2mm** になる。

PowerBoost の板の面は **79.2**。板の面から上まで切ると**へこみの底が PowerBoost の部屋へ抜ける**。

### 🔴 電池の端子は「短辺の真ん中」ではなく「奥の隅」

✅ **セルは左右どちらの向きでも入れられ、端子は手前隅・奥隅のどちらにも選べる**（ユーザー）。

## ✅ 背を 4.6mm 詰めた（2026-08-21・第1回）

**OLED の頭が天井の裏に来た**（ユーザー指示「最大まで下げた OLED の最も高さがある部分が
天面の裏になるべき」）。外寸 59.707 → **55.1**（408.4 → **376.9 cm³**、−7.7%）。

順番に4つ動かしている。**どれか1つでも戻すと高さも戻る。**

1. **OLED を上下中央から板の共通面（`BOARD_Z` 2.5）へ下げた。**ベゼルは下 2.5 / 上 4.6 の
   非対称になる（✅ ユーザー「ベゼルは少々中央じゃなくても良い」）。これで板の頭が 50.6
2. **つまみを右へ 6mm** (`KNOB_DX`)。つまみの実体の下端は座の底より 1.3 低い `Z_TOP − 21.0`
   で、天井を下げると**電池の頭を噛む**（0 のままだと 203mm³）。4.0 では足りず、**6.0 で 0**。
   ✅ ユーザー承認「右よりで良い。むしろバランスが良い」。代償は天面の左右差で、
   へこみ φ26.2 の右の余白が 13 → **8.0**（左は 13 のまま）
3. **ブリッジを 1.6mm 下げた**（`DECK_Z` 30.1 → 28.5）。電池・トンネルの屋根・つまみの裾が
   一緒に下がるので、**`IN_Z` が 1:1 で下がる**。⚠ ユーザー案の **4mm は入らない**
   （実測 線×シェル 613.9mm³）。下の階は線で埋まっていて、空いていたのは INA の段だけ
4. **トグルを 1mm 下げた**（`TGL_AT` Z 47 → 46）。胴の頭が天板を 62.4mm³ 抜けていた

ブリッジを下げるために、下の階の線を全部 1.6 ずつ落としている
（`INA_RZ` 21.6→19.9 / `AS_UP` 32.5→31.0 / `AS_RZ` 20.5→20.2 / `BAT_EZ` 31.7→30.1 /
`BAT2_Z` 20.0→18.4）。`PB_LIFT` は 3.0 → **4.6** で、PowerBoost だけ元の高さに残した
（一緒に下がると充電プラグが XIAO のソケットに 14.3mm³ 入る）。

新しく彫った逃げが3つある。

- **電池トンネルの端板**に、つまみの裾ぶんの円弧のノッチ（電池の頭より上だけ）
- **トンネルの屋根**に、会話ボタンの線の溝（幅 3.5・屋根の板だけ。スポンジの層は残す）
- **つまみの座の板**の右奥の角（X 74.5〜 / Y 45.5〜52.5 / Z 44.8〜47.2）。
  座が右へ 6mm 寄って PowerBoost の端子の上に被さったため

✅ **PowerBoost のネジは拾い直した。**ブリッジが 24〜30.1 → 22.4〜28.5 へ下がった一方、
**PowerBoost は `PB_LIFT` で元の高さに残した**ので、板は動かずブリッジだけが下へ逃げた。
実測すると、前のネジ（Z 27.0）はブリッジを **10.7mm³** 貫いて効いていたが、奥のネジ
（Z 29.0）は **1.7mm³** で、上面の 0.4mm をかすめるだけになっていた。⇒ `bridge_raw()` の
右端に台を足して拾い直し、**11.7mm³** に戻した。

⚠ **台を足す条件は「ブリッジの上面の近く」に絞ること**（`BR_ZT − 1.0 〜 BR_ZT + 2.0`）。
`BR_ZT` より上を全部拾うと、**元からブリッジの外にある上2本（Z 42.14 / 44.78）にも柱が
伸びて、つまみを 42mm³ 貫く**（実際にそうなった）。

🔒 **PowerBoost は下げられない。**ブリッジと一緒に下げると、充電プラグが XIAO の
ソケット（Z 27.5〜29.5）へ 14.3mm³ 入る。`PB_LIFT` はそのためにある。

✅ 電池の取り出しは変わらず通る（`_probe_sweep` = **0.000**、左の壁の穴 565.6mm³）。

⬜ **50.6 より下は会話ボタンが決める。**天面から 15.1 下がる胴が、電池トンネルの屋根
（頭 38.0）に載る。もっと詰めるなら**ボタンをトンネルの上からどかす**話になる。

## 🔒 PowerBoost はブリッジの構造の一部（2026-08-20 ユーザー案）

**下の段に置けなかった。**床に立てるとハブ基板の右端との隙間が唯一の通り道になり、
そこは 3.2mm しかない。PWR（3本・φ3.09）でぎりぎりで、板を 2mm でも内へ入れると
1.2mm になって通らない。中途半端に上げても効かない —— **パッド（EN は板の下から
3.07）がハブ基板の上面 15.1 を越えるまで上げる必要があり**、その時点でブリッジの
下面 24.0 を突き抜ける。

⇒ ユーザー案。**板をブリッジの構造そのものにする。**

- 板は**立てたまま**（右の内壁に平行）。**上下逆**にして JST を下へ向ける。
  🔒 コネクタの向きは変えない。**変える＝表面実装を剥がして付け直すこと**（ユーザー）
- **下側のネジ列（局所 y = 20.32）をブリッジの下面 Z 24.0 に合わせる。**
  もう1本は取付穴の並びが非対称（局所 y 18.32）なので 2mm 上になる。ずれるのは板の都合
- ⚠ **そこから 3.0mm 持ち上げてある**（`PB_LIFT`。理由は下の「充電口」）。
  ネジ列は **Z 27.0 と 29.0**。どちらもブリッジの厚み 24〜30.1 の中なので、
