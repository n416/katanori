# 筐体 v3 — 組む順番から作る

**この文書は「組む順番」と「それに要る部品・留め」を持つ。** 形（.scad）はまだ無い。
手を動かすときの版は [assembly_v3.html](../hardware/assembly_v3.html)（挿絵つき・番号はこの文書の ①〜⑬ と同じ）。作り直しは `python hardware/_asm_manual.py`。
v2 の経緯は [CASE-V2.md](CASE-V2.md)。部品の寸法は [DIMENSIONS.md](DIMENSIONS.md)。

🔴 **v2 が箱になった理由。** 内寸を決めて部品を置き、線を引いて当たり検査を通した後に、
組む手順を最後に確かめた。v3 は逆で、**ユーザーが書いた組む手順を先に置き、形はそれに従う。**
筐体の大きさは定数でなく変数にし、まず組める形を作ってから詰める。

日付: 2026-08-22。手順の原文はユーザー、精緻化と指摘は AI。

## 1. 用語

| 呼び名 | 何か |
|---|---|
| **まな板** | 底の筐体（床の板）に共通基板（ハブ）をビス止めしたもの |
| **天面＋フロント** | AS5600（つまみ）と会話ボタンを備えた天板と、OLED の窓がある前面。OLED はここに付く |
| **側面構造体** | 左の壁＋ブリッジ＋右の壁。ブリッジの下に電力計（INA226）、横に PowerBoost、上に電池 |
| **ハッチ** | 背面の板。トグル（尻尾）が付く |

🔴 **v2 の背面のケーブルレールは一旦廃止**（ユーザー）。

## 2. 組む順番（ユーザーの原文を精緻化）

各ステップに「手に持つ物」「留め」「このとき要る形」を付けた。
⬜ は決まっていないこと。**機構の案は AI からは出さない。**

### ① まな板を作る
底板にハブ基板を4本のビスで留める。ハブの穴は4つ。貫通＋ナットで、ビスの頭は床の裏・ナットはハブの上（指が届く）。
- 要る形: 床の裏のビス頭を沈めるザグリ（床は肩・スタンドに載る面）。ハブの半田面を浮かせる柱（v2 は 0.5 だった。`chk_lower` の既知 186mm³ はこれ）。

### ② ReSpeaker をまな板に立てる
OLED はここでは留めない（④で天面＋フロントに付く）。
- 🔒 **ビス無し。v2 と同じ**（2026-08-22 ユーザー）: まな板の床の溝に立て、⑫ で天面のリブが頭を 0.3 押さえる。取付穴は 2 つしか無く（§5 の絵）、使わない。
- 要る形: 床の溝（v2 の `lower` の溝と同じ）と、天面の裏のリブ（v2 の `RSP_PRESS`）。
- ⚠ XIAO の USB-C の口は右の壁（側面構造体・⑩）に開く。v2 では**殻が口の中に 0.9 入っていて、壁が Z で降りてくると殻を通れなかった**。v3 は大きさが変数なので、壁を殻の外へ出せば口はただの穴になる。⑩の検査項目。

### ③ ReSpeaker と OLED をハブに配線する
ReSpeaker からは **XIAO**（I2C・電源）と **PHIN**（J2 スピーカー出力 → ハブのリレー）の2本。OLED からは **OLED** の1本。ハブの口は全部上向きで、この時点は上が開いているので挿せる。
- OLED はこの時点で宙ぶらりん。⑤で作業台に置くので、線はまな板の横に OLED を寝かせて届く長さが要る。
- 提案: OLED の線は⑥（天面＋フロントに留めた後）に回してもよい。どちらでも線の長さは同じ。

### ④ 天面に OLED を留める
OLED を作業台に置き（表を下）、天面を被せて、天面から下りている L で受ける。
- 🔴 **2026-08-23 変更。フロントはここでは付かない。**天面のビスを 6 本から 4 本に減らすため、天面とフロントを留める 2 本を天面と壁を留める 2 本と兼用にした（下の「天面のビスを 4 本にする」）。ビスが壁まで届く物になったので、フロントは⑫で本体に付いた後、最後に前から差し込んで留める。この段でフロントを持ち歩かなくてよくなった分、⑤〜⑩は軽くなる。
- OLED の穴は四隅 67 × 43・φ2.8・穴の面は正面から 3.0。⬜ **ビスをどちらから通すか。**貫通＋ナットだと、前から通せばナットは OLED の裏（触れる）、後ろから通せば頭が OLED の裏でナットが前面（見える）。
- 天面には **AS5600 の島**（M2.5 ×2・下から通し穴＋裏に六角ポケット・[knob_v5.scad](../hardware/knob_v5.scad)）、**つまみ**（上から・E リング）、**会話ボタン（BTN2・タクト）**。
- 🔒 **天面とフロントは別部品。継ぎ目は角丸の真ん中**（2026-08-22 ユーザー決定）。理由: 1部品の L 字だと、どちらかの面が立って刷れる。天面を下にすれば OLED の窓の上辺が 60mm 超のブリッジになり、フロントを下にすればつまみの座とナットのポケットが横向きの庇になる。別部品なら両方とも見える面を下にして刷れる。代償は継ぎ目の留め（板厚 2.0 の縁にナットは入らないので、どちらかに面で重なる張り出しが要る）。⬜ 張り出しをどちらの部品に持たせ、中か外かは未決。

### ⑤ 天面側の部品をハブに配線する
**AS5600**（5本）と **BTN2**（2本）。
- 🔒 原文に無い線がこの側に2本ある（§3）: **REED**（リードスイッチ。つまみの最小音量の位置を見る物なので天面以外に無い）と **PHOUT**（スピーカー。両面テープ止めなので天面に挟む）。どちらも④で天面に付け、ここで挿す（2026-08-22 ユーザー）。
- この後、天面は線でまな板に繋がったまま横に置かれる。⑩までそのまま。フロントはまだどこにも付かず、机に置いたままになる。

### ⑥ 側面構造体を手元で組む
左の壁・ブリッジ・右の壁。ブリッジの下に INA226、横（右の壁側）に PowerBoost。電池をブリッジの上に載せる。
- INA226: 対角2穴。⬜ **径と位置は未実測**（着荷 8/21〜29・[TODO.md](TODO.md)）。
- 🔒 **PowerBoost は内側からビス**（2026-08-22 ユーザー・B案）。右の壁の内面にナットを仕込む肉を付け、穴4つ（φ2.5）のうち出力と反対の端の2つで留める。頭は中。
  v2 の差し込み（A案）は下シェルの床の柱で下を受けていたので、側面構造体を手元で組む v3 では板が下へ抜ける。
- 🔒 **左壁・ブリッジ・右壁は3部品をビスで組む**（2026-08-22 ユーザー）。壁を面で刷れる。継ぎ目は壁↔ブリッジの2か所で、ブリッジの厚み 6.1 にナットを仕込める。🔒 **横の壁にビスの頭は出さない**（2026-08-22 ユーザー）。⇒ ビスは内側から通し、ナットを受ける肉を壁の内面・ブリッジの高さに付ける（天面の四隅の柱と同じ物）。壁の外面は平ら。
- 🔒 **電池の蓋・ロック・磁石は持つ**（2026-08-22 ユーザー）。v2 の左の壁の蓋をそのまま側面構造体の左の壁に引き継ぐ。捨てる利点は壁が1枚で済むことだけで、代わりに電池交換のたびに天面のビスを外すことになるため。

### ⑦ 充電ケーブルを PowerBoost に挿し、外の口を壁に付ける
PowerBoost の micro-B に中で挿し、箱の外は Type-C。
- 🔒 **部品は決めた（2026-08-23・ユーザー「もう決めてください」→ AI が決めた）: フラット型 Type-C メス ← micro-B オス（ストレート）変換ケーブル・Amazon `B0H5BRM1YG`（長さは下で 20cm に決めた）。**
  抵抗もハンダ付けも無し（CC 抵抗の話はむき出しのコネクタを自分で付ける案の話で、既製ケーブルには出てこない）。
  ストレートなので v2 の「プラグの空間」（長さ 12）にそのまま収まり、L 型の左右の賭けが無い。
  ⬜ **2026-08-24: 「そのまま収まる」は未検証。**口の前の空きは v3 の実体で **13.5**（[SHOPPING.md](SHOPPING.md) の表）。
  ストレート品の胴の長さは非公開なので、**口から出る分（全長 − 埋まる 5.0）が 13.5 以下かどうか**は着荷で測る。入らないと言う根拠は無い。
  Type-C メス側は右の壁の内面に**ハウジングを差し込むポケット**で受け、鼻先だけ壁の穴から出す。
  🔴 **口の位置は v2 の「XIAO の口の真上」には置けない**（2026-08-23 ユーザー「結構深いですが大丈夫?」→ 当てた）。ハウジング（商品写真から仮 25 × 12 × 7）が壁から 25 奥まで入り、
  そこは PowerBoost に挿す micro-B プラグの空間と PowerBoost そのものの場所で **557mm³** 当たる。
  🔴 右の壁の後ろ寄り [Y 71.2, Z 33.5] は**ユーザー却下**（「そこが例のとんでもない場所」）。
  右の壁は前が micro-B プラグと XIAO、真ん中が PowerBoost で、残りは後ろだけ ⇒ 右の壁には置けない。
  🔴 左の壁・電池の蓋の下 [Y 44.5, Z 19.2] も**ユーザー却下**（「君の設定する場所、全部デザイン的にはおかしい」）。

### ⑧ 電池・INA226・PowerBoost を配線する
電池 JST → INA226 のネジ端子（INPUT）→ INA226（OUT）→ PowerBoost の JST。電池線は PH2.0 の延長を自作して切る（[SHOPPING.md](SHOPPING.md) 133行）。
- これで電池が生きる。PowerBoost の 5V がハブへ行くのは⑪なので、それまで基板側は無電源。

### ⑨ 側面構造体をまな板に留める
🔒 **2026-08-22 ユーザー決定: ⑩⑪の線（PWR・INA・TOGGLE）もここより前に挿す。線は 10 本全部挿してから載せる。**
🔒 **2026-08-23: 両方の壁とも上から降ろす**（一度「右の壁だけ横から」にしたが取り下げ。§「右の壁の XIAO の口」）。
側面構造体を載せた後ではブリッジの後ろの隙間（19mm）からしか口に届かないため。
側面構造体（INA226・PowerBoost・電池・充電ケーブル付き）を、ReSpeaker とハブの上から Z で降ろす。
- 検査: 降りる通り道に ReSpeaker の頭・XIAO ソケット・ハブの部品・③⑤で挿した線7本が無いこと。INA226 はブリッジの下面に付くのでハブの部品の上を通る。
- 留め: 貫通＋ナット。⬜ **横から通すか下から通すか。**どちらでも、ナットの入る場所が「閉じる前に手が届く側」に要る。
- XIAO の口: ②の注意。

### ⑩ 残りの電力配線をハブに挿す —— 🔒 ⑨ の前にやる（2026-08-22 ユーザー決定）
**PWR**（PowerBoost 5V/GND/EN・3本）と **INA**（I2C・4本）。側面構造体を手に持って掲げた状態で挿す。
- 検査: 側面構造体を載せた後、ハブの PWR と INA の口に指と線が届くか。ブリッジはハブの上を Y 19〜60 覆う（v2 の値）ので、届くのは前（ReSpeaker の裏）・後ろ（ハッチが開いている）・上（天面が無い）から。
- 届かなければ、⑨の前（側面構造体を手に持って上に掲げた状態）で挿す。線は 5cm 分長くなるだけ。

### ⑪ トグルを天板の棚に載せ、ハブに配線する
🔒 **2026-08-22 ユーザー（絵で説明）**: トグルはハッチではなく**天板にぶら下がる棚部品**に載せる。棚は天板の裏の爪に差し込んで付く。
「作業台に天面を下にしてトグルスイッチを置く」＝天板を裏返して作業台に置き、爪に棚ごとトグルを差す作業。
- トグル MTS-102 のネジ部（M6 ブッシング）は後ろを向き、⑬ でハッチの φ6 の穴を抜けて外に出る。
- ⚠ 棚の分、トグルの軸は v2（天井から 4.3）より下がる。胴 φ13 ＋ 棚の板 → 天井から 8 前後。電池の頭（Z 35.3）とは Y で重ならない（トグルの胴は Y 59.5〜、電池は 〜57.9）。模型で当て直す。
- 棚の形（爪の形・寸法）は ⬜。ユーザーの絵は [docs の ⑪ の原図]（断面: 天板 → 天板爪 → 棚部品がトグルを抱える）。

### ⑫ 天面を本体に留め、最後にフロントを差し込む
🔴 **原文に無いステップ。**④で組んだ天面は⑤から線で繋がったまま横に置かれていて、本体に留める手順が無い。
🔴 **2026-08-23 に 2 段になった。**天面のビスを 4 本にしたので、前の 2 本はフロントの耳を貫いて壁の柱のナットへ入る。
先に天面＋OLED を Z で降ろし（検査 `close_tf` **0**）、次にフロントを前から +Y へ差し込んで（検査 `close_front` **0.13mm³**＝既知の膜だけ）、
四隅の 4 本を締める。後ろの 2 本は天面と壁だけを、前の 2 本は天面・耳・壁の 3 枚をまとめて締める。
- 🔒 **留めは天面からビス**（2026-08-22 ユーザー「天面の裏だろうね。天面からビス止め。デザイン的にも良い」）。
  読み: ビスの頭は天面の表、ナットは天面のすぐ下＝側面構造体の壁の上端に先に仕込む。閉じるとき中に手は入らないが、外から回すだけで済む。
  ⇒ 壁 2.0 にナット（M2 で二面幅 4.3）は入らないので、ビスの位置だけ壁を太らせた柱（v2 の `BOSSES` と同じ）が側面構造体に要る。
- ⬜ ⑫を⑩の前にするか後にするか。前にすると⑩の「上から」が塞がる。

## 4. 設計の規則（v2 から引き継ぐ）

- 寸法は変数。内寸は手書きせず、部品＋逃げ＋手の隙間の和で持つ。最初は大きく、詰めるのは最後。
- 樹脂にネジを切らない。貫通＋ナット。ナットの場所は「そのビスを締めるときに手が届く側」。

### ブリッジを刷れる形にする（2026-08-23）

CHITUBOX に載せた実物を見ながら詰めた。**会話ではなくこの節が記録**（別スレッドは削除された）。

- **柱と L が本体から離れていた。** 波板の後端 60.335 と柱の前面 `COL_Y0` 60.37 で **0.035mm** の隙間があり、STL の殻が 2 つになっていた。原因は `BR_Y1_R`（66.368・「右端だけ後ろへ延ばす」）が定義だけで一度も使われていなかったこと。柱と重なる X を `BR_Y1_R` まで延ばして繋いだ。幅は **5mm（X 73〜78）**（🔒 別セッションのユーザー発言「剥がす時危険なので」で 2 → 5）。

##### 🔴 ついでに見つかった: 耳がどの印刷部品にも入っていなかった（2026-08-23）

### 丸みの持ち主（2026-08-23 ユーザー）

🔒 **丸みは フロント＝天面 ＞ 側面 ＞ 背面 ＞ 底面 の順で、優先の高いパーツが取る。** 理由はユーザーの言葉で

## 🔒 OLED をベゼルの中央へ下げた（2026-08-23 ユーザー「ベゼルの中央になるように下げてみてください」）

前の式は `OLED_Z0 = IN_Z - oled_w()` で、OLED の上辺を内側の天井にツライチで貼り付けていた。v2 では内寸の高さがちょうど OLED の丈（`IN_Z = oled_w()` = 48.1）だったので、これで前面が OLED で埋まって具合が良かった。v3 でトグルの胴のために内寸が 52.8 へ 4.7 伸びたとき、増えた分が全部 OLED の下の隙間に落ちて、窓だけが上へ寄っていた（下 12.2 / 上 6.6・外形の底からの数字）。

直した式は**ガラスの中心を外形の前面の中心に合わせる**もので、内寸の高さが今後また動いても窓は中央に留まる。

```
OLED_Z0 = (IN_Z + TOP_T - FLOOR_T) / 2 - (oled_glass_y() + oled_glass()[1] / 2);   // 1.9
```

- OLED の下端は床から 4.7 → **1.9**。ガラスは内寸で Z 7.4〜45.9、外形の底からは 9.4〜47.9 で、**上下のマージンが 9.4 で揃う**（前は 12.2 / 6.6）。窓（`WIN_Z`）は 7.1〜46.2 で式に追従する。
